# 웃김 검증 파이프라인 (funny-court)

영상 만들기 **전에** 주제를 거르는 단계. 교훈: `films/gravity-tunnel`은 교과서·숫자 위주라 "진심 재미없다"는 반응을 받았다. 반대 의견을 일부러 세워 그런 착각을 깬다.

## 입력
- 후보 목록(텍스트, 파일, 또는 대화 속 표). 후보마다 제목·훅·펀치라인이 있으면 좋고, 없으면 1단계가 채운다.
- 선택: 사용자 취향(웃김/소름/감동, 좋아하는 채널 분위기). 있으면 `personas.md`의 패널을 그에 맞게 조정한다.

## 진행 (Agent 도구로 서브에이전트 호출)
1. **오피스** — 후보마다 `funny-office` 에이전트(후보가 많으면 병렬). 결과: 훅(0~3초), 비트 3개, 펀치라인 A안+대안 3개, QA 판정(첫 3초 이탈 위험 상/중/하), 확인이 필요한 사실 목록.
2. **패널** — `funny-panel` 에이전트 1회에 1단계 결과 전체와 `personas.md`를 넘긴다. 페르소나별로 멈춤·웃음·공유 점수(각 10점)와 한 줄 반응. 합계 상위 3개만 통과.
3. **법정** — `funny-court` 에이전트가 상위 3개를 재판: 검사(노잼 논고) ↔ 변호(터지는 이유) → 배심원 12명 투표(유/무죄=재밌다/노잼, 한 줄 이유) → 판사가 최종 1개와 "고쳐야 살아남는 점" 판결.
4. **사실 확인** — 최종 1개의 사실·수치는 WebSearch로 출처를 확인하고, 틀리면 고친다(원문 그대로, 출처 URL 기록).

## 출력
`films/_ideas/<YYYY-MM-DD>-<slug>.md` 한 파일:
- 최종 기획 한 페이지: 제목(한국어), 훅, 비트 3~4개(초 단위), 엔딩/펀치라인, 스타일 1~2개(`$HOME/lemo-opuscar/styles/README.md`), 출처
- 패널 점수표, 법정 판결 요지
- 탈락 후보와 탈락 사유 한 줄씩

대화에는 최종 1개 요약과 파일 경로만 짧게 보여 준다.

## 규칙
- 실존 작품·브랜드·인물 이름은 제목·내용에 쓰지 않는다.
- 30초, 세로 숏폼(1080×1920)이면 그렇게, 아니면 CLAUDE.md 기본값.
- 과장 프레이밍 필수(`funny-office.md`의 과장 규칙). 사실을 담담히 전달하면 유죄.
- 판사는 "전원 기각"도 판결할 수 있다. 배심원 8/12 미만이면 통과시키지 않는다.
- 검사는 봐주지 않는다. "교과서 같다 / 숫자만 있다 / 캐릭터가 없다 / 3초 안에 안 멈춘다"는 즉시 유죄 사유.
