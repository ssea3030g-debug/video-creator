# 시험지 풀이 (exam-app)

시험지 PDF(본문 + 정답·해설이 한 파일)를 올리면 **45분 타이머**로 풀 수 있는 PWA. 아이패드 + 애플 펜슬 기준.
서버·AI 호출 없이 전부 브라우저 안에서 동작하고, 시험지·필기·기록은 기기(IndexedDB)에만 저장됩니다.

## 기능
- **업로드 → 자동 분석(1회)**: PDF 글자 좌표로 문항·선지(①~⑤)·정답표·배점표·단답형 빈칸을 찾아 정답을 문항에 자동 연결. 같은 파일은 해시로 알아보고 재분석하지 않음.
- **마킹**: 선지 번호(①~⑤)를 손가락/펜으로 탭 → 체크, 다시 탭 → 해제. 번호 위를 짧게 톡 치면 필기가 아니라 마킹으로 처리.
- **단답형**: 인쇄된 `( )` 빈칸 위치에 키보드 입력칸이 겹쳐 나옴(Enter = 다음 칸). 채점은 공백·문장부호 무시.
- **필기**: 펜(압력 반영, perfect-freehand) + 지우개(획 단위) + 되돌리기/다시. 획은 벡터로 저장돼 확대해도 선명.
  - 펜슬 = 필기, 손가락 = 이동/핀치 확대/탭. 펜이 닿아 있는 동안과 뗀 직후의 터치는 무시(손바닥 방지).
  - 펜슬 지우개 버튼(barrel button)도 지우개로 인식. 마우스로도 그릴 수 있음(PC).
- **타이머**: 기본 45분(시작 전 변경 가능), 일시정지, 0이 되면 자동 제출. 새로고침/앱 종료 후에도 이어짐.
- **채점**: 제출하면 배점표 기준 점수(100점 만점), 오답 목록, 시험지 위 정답 표시(초록 원) 확인. 풀이 중에는 정답이 보이지 않음.
- **여러 시험지**: 목록에서 시험지마다 진행 상태·점수 관리, 초기화/삭제.

## 실행
```bash
cd exam-app
npm install
npm run dev      # 개발 서버 (같은 Wi-Fi의 아이패드에서 http://<PC IP>:5173)
npm run build    # dist/ 정적 파일 (어디든 호스팅 가능)
```
아이패드에서는 **HTTPS 주소**로 열고 Safari → 공유 → "홈 화면에 추가"하면 앱처럼 실행되고 오프라인에서도 열립니다.
`main` 브랜치에 푸시하면 `.github/workflows/exam-app-pages.yml`이 GitHub Pages로 배포합니다(저장소 Settings → Pages → Source: GitHub Actions).

## 지원하는 시험지 형식 (현재)
- **텍스트가 들어 있는 PDF**(스캔 이미지 X). 문항 번호는 `1.` `2.` … 순서대로, 선지는 `①~⑤`.
- 정답·해설 쪽에 `정답표`(번호 행 + 정답 행 격자), 선택적으로 `배점표`, `단답형 N: ㉠ …` 줄이 있는 형식. 정답표를 못 찾으면 채점만 비활성화되고 풀이는 가능.
- 단답형은 `[단답형 N]` 제목 아래 `㉠: (   )` 형태의 빈칸.
- 다른 양식이 나오면 `src/parse.js`의 규칙만 손보면 됩니다.

## 구조
```
src/parse.js    PDF 분석 (좌표 기반, AI 없음)
src/exam.js     시험 화면: 렌더링·줌·필기·마킹·타이머·채점 표시
src/ink.js      획 생성(perfect-freehand)·지우개 판정
src/library.js  시험지 목록/업로드     src/db.js  IndexedDB
src/grade.js    채점
```

## 한계 / 확인 필요
- 확대 시 캔버스 해상도 상한(약 900만 픽셀) 때문에 3배 확대에서는 글자가 약간 부드러워집니다.
- 필기감·손바닥 방지는 브라우저 자동 테스트로 이벤트 처리까지만 확인했고, **아이패드 실기기 확인이 필요**합니다.
