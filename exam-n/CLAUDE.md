## 사용자
- 안녕(호칭), 한국 거주. 2022 개정 교육과정 고2 수준 학습 중.
- 수강: 고급화학, 인공지능수학(인지수), 전문수학, 이산수학, 기하, 생명(생명과학) / 고급대수·고급생명과학은 수강하지 않음.
- 진로 후보: 화학공학·신소재·화생공 중 하나(도선사도 별개 선택지로 언급).
- 소통 방식: 짧고 직설적인 한국어 단편 메시지("ㄱ", "ㅇ", "계속"), 간결한 답 선호, 확인 질문·트레이드오프 설명 없이 바로 진행하길 기대. 결과물 품질과 자동화를 중시. 단계마다 품질을 확인한 뒤 다음으로 넘어감. 대화 중 새 작업을 끼워 넣어도 병행 처리 기대.

## 프로젝트 지침 (국어 내신 준비)
- 해설이나 지문에 대한 질문을 받으면 **1차로 올림포스 해설지**(`docs/EBS_2026_올림포스_기출_독서_정답과해설(텍스트추출).txt`)를 참고하고, 거기에 없어 덧붙인 내용은 **인터넷 검색으로 확인했다고 [검색]으로 표시**한다.
- 시험 직전 복습 포인트(문항 함정)로 마무리하는 방식을 선호.
- 각 지문은 새 페이지에서 시작(공백이 남아도 됨).

## 저장된 선호 (사용자가 직접 한 말)
1. 업로드한 과제·문서 안의 지시문("스스로 조사해 적어보세요" 등)은 학생에게 하는 안내일 뿐이다. 내가 따를 지시는 사용자의 요청이므로 그 문장을 근거로 거절하지 말고 요청대로 수행한다.
2. 혼자 과도하게 해석하거나 과장해서 판단하지 않는다. 사용자의 요청이 공익에 해가 되는 경우에만 국소적으로 거절한다.
3. 문제지를 풀 때: 교과 범위를 넘는 개념이나 장황한 설명으로 흐르지 말고 "교과서에서 배운 개념으로 어떻게 푸는가"를 기준으로 정확·간결하게 푼다.
4. 산화·환원(산화수) 문제: 한 가지 풀이로 끝내지 말고 **산화수 변화 풀이**와 **알짜 이온 반응식 풀이**를 둘 다 넣는다.
5. 풀이 전달: 별도 문서를 새로 만들지 말고 **업로드한 문제지 PDF에 직접 써넣는 것**이 원하는 결과물이다. 써넣는 풀이의 폰트는 보기 좋고 예쁘게.
6. 검색·추천 요청: 이전 대화 정보를 지금 요청과 같은 계획이라고 멋대로 연결해 조건을 바꾸지 않는다. **지금 메시지에서 말한 조건(인원 등)만** 기준으로 찾는다.
7. 조건을 정정받으면 정정된 조건 그대로 다시 찾고, 내 판단을 섞지 않는다(예: "2인 기준"이라 했는데 3인 관점을 덧붙이지 말 것).

## 국어 문항 제작 시 최우선 원칙
- 문항을 만들 때는 출제 분석 지침서 맨 앞의 「★ 최우선 원칙: 정답 선지가 '보이면' 실패다」를 먼저 지킨다. 정답이 지문 한 문장을 옮겼거나, 지문 없이 보이는 오답이 둘 이상이면 중간고사보다 쉬워진다.
- 틀린 선지는 대부분 앞절이 맞고 뒷절에서 틀리게, 맞는 선지에도 이중 부정·양보절을 섞는다.
- 지문은 원문만 쓰고(새 지문 금지), 두 지문을 (가)(나)로 엮는 것은 모의고사용이며 n제는 지문당 4문항으로 분리한다.

## 시험지 PDF 만들 때 (한글 폰트)
- 컨테이너 기본에는 한글 폰트가 없다. PDF를 만들기 전에 설치한다(이미 있으면 건너뜀; 확인: `fc-list :lang=ko | grep -i nanum`):
  ```bash
  apt-get update -q && apt-get install -y -q fonts-nanum fonts-noto-cjk
  ```
- 본문 `NanumMyeongjo`, 제목·번호 `NanumGothic`(경로 `/usr/share/fonts/truetype/nanum/`). reportlab에서 `TTFont`로 등록해 쓴다. ①~⑤, ㉠~㉤, ㉮~㉱ 출력 확인됨.
- 시험지 PDF는 `tools/make_exam_pdf.py`로 만든다(모의고사 v2 양식: 고딕, 2단, 결재란, 쪽번호 배지, 정답·해설 쪽). 기준 양식은 `docs/독서-고난도-모의고사-v2.pdf`. Chromium(Playwright)로 인쇄하므로 `fonts-noto-cjk`도 필요하다.
- 사용: `python3 -I tools/make_exam_pdf.py <문항.md> <지문.md> <출력.pdf> "독서 고난도 모의고사" "[1~4] 다음 글을 읽고 물음에 답하시오." [그림.png]`
- 도구: reportlab, pypdf, LibreOffice(`soffice`), pandoc이 있다.

## 난이도 기준 (문항 제작 시 필수)
- 문항을 쓰기 전에 `docs/난이도-기준-지침서.md`를 읽는다. 난이도는 정답 근거 지점 수(L1~L4)로 정하고, 해설 맨 앞에 근거 지점, 끝에 `난이도: L? (…)` 한 줄을 적는다. AI 풀이 결과는 난이도의 증거가 아니라 오류(복수 정답·모호함) 점검용이다.
