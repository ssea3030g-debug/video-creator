# Claude Code로 옮기는 방법

1. 이 폴더 전체를 작업할 위치에 풀어 놓는다. 예: `~/국어-내신/`
2. 그 폴더에서 터미널을 열고 `claude`를 실행한다.
   - 폴더 맨 위의 `CLAUDE.md`를 Claude Code가 시작할 때 자동으로 읽는다(선호·프로젝트 지침·자료 위치가 들어 있다).
3. `memory/` 와 `docs/` 는 자동으로 읽히지 않는다. 필요할 때 "memory/japan-trip.md 읽고 이어서 해줘"처럼 파일을 지정하거나, `CLAUDE.md`에 `@memory/00-profile.md` 처럼 줄을 추가하면 매번 불러온다.

## 폴더 구성
- `CLAUDE.md` — 항상 적용할 지침(선호, 프로젝트 규칙, 자료 위치)
- `memory/` — claude.ai 메모리(프로필, 과제 진행 상황, 일본여행, 물리 수행 답안 등)
- `docs/` — 프로젝트 문서(출제 분석 지침서, 파트별 출제자 사고방식, 모의고사 제작 규칙, 올림포스 해설지 텍스트, 원본발췌 26선 PDF)

## 옮기지 못한 것
- 프로젝트 문서 중 모의고사 결과물 4개(기말-고난도-모의고사 v2 / 통합본 / 1부 / 2부)는 claude.ai 프로젝트 화면에서 직접 내려받아 `docs/`에 넣으면 된다.
- 올림포스 해설지는 원본 PDF가 아니라 텍스트로 추출된 파일만 받을 수 있었다.
- claude.ai 메모리 자체가 Claude Code로 자동 동기화되지는 않는다. 이 폴더는 오늘(2026-11-16) 시점의 복사본이다.
