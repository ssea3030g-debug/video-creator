# 난이도 상향 프로토콜 (계획안, 2026-11-22)

> 목표: 중간고사·v2·v4 수준("최상")을 **처음 쓸 때부터** 맞춘다. 사후 검수로 고치는 대신 설계 단계에서 막는다.
> 금지선은 그대로: 복수 정답·모호함·지문 밖 지식·계산 3단계 이상은 난이도가 아니라 오류다.

## 0. 진단: 왜 쉬워졌나 (v6 검수보고서·실수 유의사항·최상 메커니즘에서 확인된 것)

## 1. 설계 단계 강제 (쓰기 전에)
### 1-1. 설계 카드 (문항마다 한 줄, 선지보다 먼저)
```
Q7 | 인문 | 개념 교차 비교 | 슬롯 M7 | 목표 L3 | 3.0 | 정답 ③ | 근거: 2문단 3문장 + 4문단 1문장 | 오답 기법: ①맞바꿈 ②방향 ④한정어 ⑤다른 학자 참말 | 위장 참 선지: ② 이중 부정
```
- **근거가 한 곳뿐이면 그 문항은 L1이다.** 목표 L2 이상이면 근거 두 곳을 찾을 때까지 정답을 쓰지 않는다.
- 오답 기법 칸에 같은 기법이 두 번 나오면 다시 설계한다.
- "지문 없이 틀린 게 보이는 오답" 칸을 따로 둔다(0~1개).

### 1-2. 회차 설계표에서 먼저 맞출 수치
- L3·L4 ≥ 55%, L4 ≥ 세트당 1개(9~10문항), L1 ≤ 세트당 1개.
- 슬롯 M1~M8 할당량(핵심 틀 8장)을 문항 번호에 배정.
- <보기> 16개 안팎, 과학 <보기>는 수치·표, 법 <보기>는 날짜·서식.
- 오답 기법 분포: 앞참뒤거짓 ≤ 40%.

### 1-3. 정답 역설계 순서
1. 급소표(파트별: 입장표·요건표·경로표·계보표)에서 **떨어진 두 칸**을 고른다.
2. 두 칸을 이어야 참이 되는 문장으로 정답을 쓴다("적절하지 않은 것"이면 앞절 참 + 뒷절 거짓).
3. 같은 뼈대·같은 길이로 오답 넷을 쓴다. 각 오답의 재료는 **지문 속 다른 대상의 참말 / 인접 단계 / 상대 학자 / 직관값** 중에서.
4. 참 선지 하나에 위장(이중 부정·양보절·"~해야만")을 붙인다.

## 2. 객관 신호 측정 (토큰 0~소량)
사람의 감이나 Claude 자기 평가 대신, 쉬움을 **숫자로** 잡는다.

| 신호 | 방법 | 기준(걸리면 재작성) | 비용 |
|---|---|---|---|
| S1 지문 복사도 | 정답 선지와 지문 각 문장의 글자 3-gram 겹침률(스크립트) | 최댓값 ≥ 0.6이면 "한 문장 복사" 의심(일치 L1 제외) | 0 |
| S2 극단어 오답 | "아무런·전혀·오직·~에만·결코" 등 사전 매칭 | 문항당 2개 이상 | 0 |
| S3 길이 단서 | 정답 길이 순위, ±35% 이탈, 파트별 길이대 | 기존 `check_set.py` + 파트 길이대 | 0 |
| S4 기법 분포 | 설계 카드의 기법 태그 집계 | 같은 문항 내 중복, 회차 앞참뒤거짓 > 40% | 0 |
| S5 **지문 가리고 풀기** | 무료 모델에 **문항만**(지문 없이) 주고 풀게 함 | 정답을 맞히면 B축 = 0 → 소거로 풀리는 문항 | 무료 |
| S6 지문 주고 풀기 | 무료 모델에 지문 + 문항(오류 검수와 같은 호출) | 근거 한 문장으로 고확신 정답 → "쉬울 수 있음" | 무료 |

- S5가 핵심이다. 지침의 B축("지문을 가리고 풀었을 때 정답이 서는가")을 그대로 측정한다. 5지선다라 우연히 맞힐 확률 20%를 감안해, **확신 높음 + 맞힘**일 때만 걸리게 한다.
- S5·S6은 2단계 오류 검수의 무료 모델 호출과 묶어 한 번에 보낸다(호출 수 늘리지 않음).
- 외부 모델에 보내는 문서에는 L 태그·해설·자기 평가 문구를 넣지 않는다.

## 3. 재작성 규칙
- 신호에 걸린 문항만, **최대 1회** 재작성. 고칠 레버는 B·C축(오답 재료 교체, 위장 참 선지, 앞참뒤거짓 → 고리 하나 바꾼 사슬)이다. A·E축(근거 수·계산 단계)을 무리하게 늘리지 않는다.
- 재작성 뒤에도 걸리면 고치지 말고 "난이도 미달 후보"로 보고한다(사용자 판정).
- 재작성으로 핵심 수치·조건을 지우지 않는다(실수 22).

## 4. L 판정 정직화
- L은 5축 점수를 먼저 적고 합으로 정한다(태그를 먼저 정하지 않는다).
- 회차 보고에는 5축 합으로 다시 센 분포만 쓴다. 보고와 해설의 L이 다르면 해설을 고친다.
- S5에서 걸린 문항은 B축을 0으로 내려 다시 합산한다.

## 5. 피드백 루프 (회차가 끝날 때)
- 사용자가 "쉽다"고 판정한 문항은 원인을 0장 표의 번호로 분류해 `실수-유의사항.md`에 규칙으로 추가한다.
- 같은 원인이 두 회차 연속이면 `핵심-틀.md` 해당 절에 한 줄 반영한다.
- 학교 정답표·정답률이 들어오면 L 환산표(핵심 틀 3장 배점 눈높이)만 보정한다.
