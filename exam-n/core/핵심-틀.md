# 출제 핵심 틀 (문항 제작 때 이 문서만 본다)

> 지침서 압축본(`exam-n/guide/`, 약 64KB)에서 **문항을 만들 때 필요한 틀만** 한 장으로 뽑았다. 문항 제작은 이 문서 + 해당 지문만 보고 한다.
> 압축본 전체는 사용자가 "지침 검수"를 요청할 때만 연다(`작업-흐름.md` 3단계). 원문은 `exam-n/docs/`(현재 `claude/vibrant-einstein-iskm3i` 브랜치). 출처 표기 예: [지침 8-4] = 출제분석 지침서 8-4절, [사고 H7] = 파트별 사고방식 H7, [난이도] = 난이도 기준 지침서, [보완] = 난이도 보완, [실수 20] = 실수 유의사항 20번, [최상 M2] = 최상 메커니즘 M2.

## 0. 최우선 원칙: 정답이 "보이면" 실패 [지침 ★]
1. "가장 적절한 것"의 정답은 **지문 문장을 옮기지 않는다.** 떨어진 두 문장, 또는 <보기> 조건 둘을 이어야 참이 된다.
2. "적절하지 않은 것"의 정답은 **앞절 참 + 뒷절 거짓**(또는 인과 사슬의 한 고리만 거짓). 극단어·상식 위반으로 정답을 만들지 않는다.
3. 맞는 선지 넷도 정답만큼 길고 그럴듯하게. 참 선지 위장(이중 부정·양보절)은 **회차 전체 3~5문항 이하**로 쓴다(중간고사 실측 11-2). 위장으로 난이도를 올리지 않고, 참 선지는 지문 두 곳을 잇는 정직한 서술로 쓴다.
4. 지문 없이 틀린 게 보이는 오답은 **문항당 0~1개.** 나머지는 다른 대상의 참말, 그럴듯한 가짜 기제, 고리 하나만 바꾼 문장.
5. 학생이 실제로 하는 착각을 노린다(위치 순서 = 손상 순서, 분모 2배 = 절반).
6. **지문 문장을 옮기지 않고 자기 말로 다시 쓴다.** 지문에서는 핵심 용어(개념어·고유명·정의된 술어)만 가져오고, 용어를 잇는 서술(인과·비교·조건·결론)은 새 문장으로 쓴다.
   - 중간고사 원문 실측(33문항, 정답은 추정 키 `sets/calib/mid.json`, 공백·부호 뺀 글자 기준, "지문과 6자 이상 연속으로 같은 부분"을 인용으로 침):
     · 정답 선지 중 인용 부분의 비율은 평균 0.20, 중앙값 0.14이고 오답 평균도 0.20이다. 정답이 오답보다 지문과 더 비슷한 문항은 14/33이고, 오답 최대보다도 높은 문항은 5/33뿐이다.
     · 정답에서 가장 길게 이어서 인용한 길이는 중앙값 7자(평균 6.8자). 27/33문항이 9자 이하, 곧 용어·짧은 구(예: "동일률이나 모순율", "경험에서 비롯", "편익을 제공하는 토지") 수준이다. 15자 이상은 3문항(법 9번 20자, 과학 21번 24자, 과학 17번 18자)이고 모두 법적 효과·정의된 지표·구조 서술이다.
     · 분포: 인용 비율 0.1 미만 12문항, 0.1~0.2 8문항, 0.2~0.3 4문항, 0.3~0.5 5문항, 0.5 이상 4문항(법 9·12, 과학 17·21).
     · 파트별 정답 인용 비율: 예술 0.08 < 인문 0.14 < 법 0.26 < 과학 0.31. 인문·예술은 새 말로 구조를 요약하고(인문 1번은 인용 0.00: "(가)와 (다)는 기존의 관점을 먼저 제시한 뒤 …" 형태로 지문에 없는 문장), 법·과학은 정의·요건·수치 용어를 지문 그대로 쓴다.
   - 규칙: ① 정답 선지는 지문 문장을 통째로, 또는 15자 넘는 구절을 이어서 복사하지 않는다. 용어는 10자 안팎 단위로만 가져온다. ② 정답의 인용 비율이 오답 최대보다 높지 않게 한다(오답이 지문 말을 더 많이 써도 된다). ③ 파트별 목표 인용 비율: 인문 0.1~0.2, 예술 0.1 안팎, 법 0.2~0.3, 과학 0.3까지. 이를 넘는 문항은 법·과학의 정의·요건·수치·날짜·조건에 한한다. ④ 정답만 지문 말로 짜 맞추고 오답은 새 말로 쓰는 불균형을 피한다(오답도 같은 정도로 지문 용어를 쓴다). ⑤ 점검은 `check_hard.py` S1과 이 인용 비율(0.5를 넘으면 직접 확인).
   - 한계: 정답 키는 추정이고, 글자 단위 일치라 의미를 비슷하게 바꾼 정도(유의어·어순)는 인용으로 세지 못한다. 변환 결과(학교 시험지 본문)는 저장소에 두지 않았다(수치만 기록).
- 예외: 2.4~2.6점 세부 일치는 한 곳만 바꿔도 된다. 회차당 3문항 이하 [최상 9].

## 1. 시험 체제 [모의고사용 1·4·5]
- 9세트, 선택형 33 + 단답형 2 = 35문항, 100점(95 + 5). 순서: 인문 → 사회 → 과학·기술 → 예술. 분야별 약 25점.
- 단답형은 해당 지문의 선택형 바로 뒤에("[6~9, 단답형 1]").
- <보기> 문항 16개 안팎(3.0점 이상 15문항 중 12개가 <보기>). 어휘 4문항(네 유형 하나씩, 지문당 1개).
- 발문 극성 반반. 정답 번호 ①~⑤ 각 6~7개, 같은 번호 연속 2문항까지, 같은 짝(④→②)이 세트 첫머리에 반복되지 않게 [실수 11].
- 지문은 원문만(새 지문·수정 금지). 계산식이 필요하면 <보기> 안에 짧게.
- n제: 지문당 4문항 단독 세트. 모의고사: (가)(나)(다)로 엮음.

## 2. 세트 구성 공식 [지침 8-3, 11-3]
| 세트 형태 | 문항 | 구성 |
|---|---|---|
| 단독 지문 | 3~4 | 일치/전개 1 + 비교·추론 1 + <보기> 1 (+ 어휘 1) |
| 2지문 | 4~5 | 전개·일치 1 + 교차 비교·추론 1 + 지문별 <보기> 1~2 + **통합 <보기> 1** (+ 어휘) |
| 3지문 | 5 | 전개 1 + 지문별 <보기> 3 + **3지문 통합 1** |
- 배치: 첫 문항 L1~L2 → 가운데 L2 → 끝 <보기> L3~L4. 세트마다 L3 이상 1개 이상.
- 지문마다 단독 <보기> 1 + 통합 문항 1이 기본. 한 세트에서 같은 급소를 두 번 묻지 않는다.
- 원본 밑줄 위치를 피해 새로 친다. 원본에서 '적절한' 선지였던 내용을 뒤집어 정답으로 쓰는 문항을 세트마다 하나쯤 넣는다.

## 3. 파트별 출제자 틀 (한 파트 틀을 다른 파트에 쓰지 않는다) [사고 1·5]
**인문은 "정도", 법은 "조건", 과학은 "단계"를 흔든다.**

| | 인문 | 사회(법) | 과학·기술 | 예술 |
|---|---|---|---|---|
| 급소표 | 학자 × 인정 × 부정 × 사례 | 제도 × 요건 × 효과 × 예외 | 단계 × 단위 × 변화 × 한계 | 이론가 × 개념 × 사조 × 대립 쌍 |
| 정답 모양 | 정도가 조절된 문장("일부", "직접 입증할 수는 없다") | 조건과 결론이 맞물린 문장, 의무 쪽 당사자 | 두 문장 합친 재진술, 계산 결과 | "A와 달리 B는"의 전제 판정 |
| 오답 주력 | 방향·정도·시간 한정어 한 곳, 상대 학자의 결론 붙이기 | 요건 제거/추가, 제도 맞바꿈, 다른 제도의 참말 | 한 낱말 교체, 인접 단계 기능 이동, 가짜 기제, 직관값 | 공통점을 "달리"로, 인물 교체, 앞참뒤거짓 |
| 참 선지 위장 | 이중 부정 [H7] | 같은 "~해야만"을 참·거짓에 한 번씩 [법1] | 양보절 "~더라도" [S9] | 앞절 참 |
| <보기> | 서사, 지문 어휘를 심음. 앞절 <보기> 복사 + 뒷절 지문 개념 [H9] | 날짜·등기부·갑을병, 법률어 대신 상황으로 풀어 씀 [법7] | 이름표 지운 표·수치·단서 "(단, …)" [S11] | 실존 외부 이론 5~6문장, 실제 작품, ㄱ~ㄹ 진술 |
| 선지 길이(공백 제외) | 80~86자 | 55~64자 | 55~68자 | 37~47자(어휘 제외) |
| 말끝 | ~겠군 | ~겠군 | ~때문이다 | 짧게 |
| 배점 눈높이 | L1 2.5 / L2 2.7~2.9 / L3 3.0~3.2 / L4 3.3 | L1 2.4~2.5 / L3 2.9~3.1, **3.2 이상 금지** | L2 2.6~2.9 / L3 3.0 / L4 3.3 | 조합·외부 이론 3.1~3.3 |

파트별 핵심 레시피
- 인문 H1: 학자가 인정하는 것 / 부정하는 것을 선지 둘에 나눠 담고(둘 다 참), 오답은 그 학자에 상대 학자의 결론을 "~만으로"로 붙인다.
- 인문 H2: 종합 견해 <보기>(문장마다 지문 하나 대응, 한 문장은 두 학파 요소를 섞음) → 정답은 '일부 수용'. 오답 하나는 "일부"를 쓰되 이유를 틀리게(정답 요령 차단).
- 인문 H5(전개 방식): "구조는 같고 장치가 다른" 짝이 정답. 오답 = 장치 이동, 주제 맞바꿈, "모두" 과잉, "그치는". **지문에 없는 전개(절충·시대순)만으로 오답 넷을 채우지 않는다.**
- 인문 H8: 비판받는 기존 견해에도 선지 하나.
- 법 L4: 날짜 선지는 모두 참으로 계산 가능하게, 거짓은 숫자 없는 개념 선지. **단, 회차마다 반대 패턴(날짜 선지가 틀림, 기산일 등)도 섞는다** [실수 7].
- 법 L5: 이유 추론의 오답 = 지문 속 다른 제도의 참말 2 + 비튼 재료 2.
- 법 L8: 지문에 없는 법률어(철회·상속인)를 오답 1~2개에. 틀린 이유는 지문 요건으로 설명돼야 한다.
- 과학 S4: 역설형 <보기>(모순처럼 보이는 상황 → 떨어진 두 문장으로 해소). 오답 = 가짜 기제 3 + 한 지문 특성을 양쪽에 붙인 "모두" 1.
- 과학 S6: 수치는 참으로 깔고, 마지막에 두 변수를 동시에 바꿔 직관값을 오답으로.
- 과학 S7: what-if 사슬의 고리 한 곳만 틀림, 결론은 그럴듯하게.
- 예술 A2: 3분류 외부 이론 → 선지 3개는 지문 속 사건, 2개는 "~했다면" 가정 장면.
- 경제·정치 지문은 중간고사 근거가 없다. 법 틀은 쓰지 않고, "계산 선지는 참, 개념 선지에서 틀림"만 옮겨 쓴다.

## 4. 오답 기법 (한 문항의 오답 넷은 서로 다른 기법) [지침 4장, 최상 8]
① 주체·대상 바꿔치기 ② 방향 뒤집기 ③ 한정어·조건 덧붙이기("~만으로", "~전까지는", "모두") ④ 범주 혼동(비슷한 다른 개념) ⑤ 앞절 참 + 뒷절 거짓 ⑥ 지문에 없는 그럴듯한 기제
+ "A와 달리 B는"(B 진술은 맞지만 A도 그러함) / 자리 바꾼 참말(다른 대상의 참인 문장) / 직관 계산값
- 극단어("아무런·전혀·오직") 오답은 문항당 1개까지.
- 회차 전체에서 ⑤(앞참뒤거짓)는 **40% 이하.** 나머지 기법을 고르게.
- 틀린 선지는 **정확히 한 군데**만 틀린다(두 곳이면 복수 근거).
- "모두"로 묶은 공통점 선지: 오답이면 한 지문에만 있는 특성을 넓힌 것.

## 5. 선지·<보기> 형식 [지침 8-4, 8-5, 11-2, 12장]
- 다섯 선지는 같은 뼈대. 길이 차이는 평균의 35% 안. 정답이 가장 긴 선지인 문항은 전체 40% 이하.
- 뼈대: "[학자]의 관점에서, [<보기> 요소]는 [지문 개념]으로 볼 수 있다" / "[자료 현상]은, [지문 원리] 때문이다" / "(가)와 (나)는 모두 ~지만, (가)는 ~ 반면 (나)는 ~" / "A는 ~지만, B는 ~".
- 복수 지문 문항: 선지를 지문 순서대로 3:2 또는 2:3, 교차 선지는 ④⑤. 어느 지문도 빠지지 않는다. 밑줄 기호도 두 지문에 나눠 친다.
- <보기> 구획 2~3개, 구획마다 선지 1~2개, 마지막에 교차 선지 1개.
- <보기>에는 **사실만** 쓰고 해석은 지문에서 끌어오게. <보기>가 정답을 말해 주면 실패.
- <보기> 기법: 동형 사례 치환 / 형식 전환(그래프→표·조건문) / 수치·날짜 삽입 / 현대 사례 여러 렌즈 / 지문 간 융합 장치 / 실존 외부 이론 요약 / ㄱ~ㄹ 진술 / 실제 작품.
- 과정 결합형(지침 10-4): 두 지문의 흐름을 단계로 쪼갬 → 같은 물리량이 같은 방향으로 움직이는 단계를 짝지음 → 지문에 없는 새 장치를 X·Y로 익명화 → 수치 조건 2~3개 → 선지: 대응 2 + 법칙 1 + 계산(참) 1 + 조건 변경 계산(직관 함정) 1. 앞 문항에 공통 원리 선지로 다리를 놓는다.

## 6. 어휘·단답형 [모의고사용 6, 실수 1·2·20]
- 어휘는 선생님처럼 **선지를 직접 짓는다.** 동의어 바꿔 쓰기(포획→사로잡기)는 쓰지 않는다.
  - 사전적 의미(3.2점): 정답 하나만 사전 뜻풀이, 나머지는 한 단어 바꿈(가로→세로), 주체 뒤집기, 비슷한 말의 뜻풀이, 동음 한자어(産出/算出).
  - 문맥 풀이: "~라는 의미로 쓰였다". 오답은 비슷해 보이는 다른 뜻(일탈→포기). 반대 뜻으로 만들지 않는다.
  - 다의어: 같은 단어의 **서로 다른** 뜻 예문 4개. 가장 그럴듯한 다른 뜻을 매력적 오답으로.
  - 구절 바꿔 쓰기: 지시 대상 인물·개념으로 바꿔 쓰고 오답은 인물 교체.
  - 뜻풀이는 기억으로 쓰지 않고 표준국어대사전과 대조한다.
- 단답형: **사례 추론형.** <보기> 사례에서 개념을 추론하고 사례 속 인물도 채우게. **음절 수 힌트 금지**(출제분석 8-6의 음절 지정은 폐기, guide/00-색인 충돌표), 정의 문장 복사 금지. 빈칸 앞뒤 문장이 지문의 특정 문단·개념 하나만 가리키게 해서 답을 하나로 고정. 칸당 1점.

## 7. 난이도 L (다섯 축 점수제) [보완 2·3]
| 축 | 0 | 1 | 2 |
|---|---|---|---|
| A 근거 지점 | 지문 한 문장 | 두 곳, 또는 <보기> 1 + 지문 1 | 세 곳 이상, 두 지문 통합, 외부 이론 |
| B 소거 저항 | 지문 없이 틀린 오답 2개 이상 | 1개 | 0개 |
| C 변조 은밀도 | 낱말·극단어 교체 | 한정어 한 군데 | 앞참뒤거짓, 위장 참 선지, 다른 대상의 참말 |
| D 정보 변환 | <보기> 없음 / 지문 어휘 그대로 | 상황을 지문 용어로 번역 | 이름표 없는 수치·표·날짜를 스스로 판정 |
| E 연산·조합 | 없음 | 단순 조합, 날짜 1회 | 2단계 계산, 두 변수 동시 변경, 진술×학자 |
- 합 0~2 L1 / 3~4 L2 / 5~6 L3 / 7~10 L4.
- 감점(단계 하나 내림): 정답이 지문 문장 복사, 지문 없이 보이는 오답 2개 이상, 정답만 혼자 길거나 친절함, <보기>가 정답을 말함, 통합 문항이 한 지문만으로 풀림.
- **목표(최상)**: L3·L4가 55% 이상, L4는 세트당 1개 이상(회차 9~10문항), L1은 세트당 1개 이하.
- 난이도를 올리는 레버는 **B·C축**이다. A·E를 무한히 늘리지 않는다.
- 금지(과잉 난이도): 복수 정답·모호함, 지문 밖 배경지식 요구, 계산 3단계 이상, 선지 한 문장에 조건 4개 이상, 지문 원문 손대기, 외부 지식이 있어야만 판정되는 융합.
- 배점은 L의 결과. 같은 출제자 안에서 L이 낮은 문항이 더 높은 배점이면 역전.

## 11. 기존 시험지의 선지 보완 규칙 (v2 보완에서 검증, 2026-11-26)
> 새로 만들 때가 아니라 **이미 있는 시험지의 오답을 손볼 때** 쓴다. 사용자 지시는 "문제만 보완, 헷갈리는 선지 2~3개".

**11-1 기준과 범위**
- 기준은 **앱에 올라간 최종 PDF**다. md는 옛 판일 수 있다(v2: 22·29번, 단답형 1·2, 배점 3곳이 달랐고, 그 때문에 보완판이 옛 문항으로 되돌아갔다). 시작 전에 `python3 -I tools/diff_pdf_md.py <앱 PDF> <md>`로 대조하고, 다르면 PDF를 따른다.
- 바꾸는 것은 오답(또는 "않은" 발문에서 참 선지의 서술 상세)뿐이다. **지문·발문·배점·정답 번호·정답 선지는 그대로.** 지문 수정·보강, 지문 밖 법리·지식("다음 날 0시" 같은 것) 추가는 하지 않는다.
- 문항당 1~3개. 이미 헷갈리는 오답은 두고, 지문 없이 틀린 게 보이는 오답만 바꾼다.
- 예외: "않은·일치하지 않는" 발문에서 **정답(거짓) 선지** 자체가 지문 없이도 틀려 보이면 그 서술만 다듬을 수 있다(정답 번호·해설 근거는 그대로, 보완한 선지로 해설에 표시). 예) v5 28번 ④.
- 어휘 문항은 표준국어대사전 사이트(stdict.korean.go.kr)에서 뜻풀이 번호와 용례를 직접 대조한다(v5 30번 '취하다': 입장 취하다 2「2」 ↔ 자세 취하다 2「3」 확인).
- 단답형은 구체적 사례 <보기>에 개념을 적용하게 한다. 음절 수 힌트는 쓰지 않는다(6장).

**11-2 이중 부정·양보 위장 상한**
- 실측(이중 부정·양보형 선지, 33문항·선지 165개): 중간고사 4개(3문항), v2 원본 9개(7문항), 위장을 더한 보완판 12개(9문항) → 보완판이 읽기 피로만 늘렸다는 검토를 받아 철회했다.
- **회차 전체 3~5문항 이하.** 위장을 난이도 레버로 쓰지 않는다. 대신 11-3의 기법을 쓴다.

**11-3 오답 설계 기법 (v2 보완에서 쓴 것, 한 군데만 틀리고 지문 두 곳 이상으로 반박)**
- **인과 방향·선후 역전**: 증가↔감소, 선행↔후행. 예) 자기정전은 정전용량 증가, 상호정전은 감소 / 안압은 배출이 막힐 때 오른다.
- **두 학자·명제 결합**: 한 선지가 둘 이상의 입장·평가를 함께 검증하게 한다(평가를 맞바꾼 선지 포함).
- **원칙–예외 결합**: 한 문단의 원칙에 다른 문단의 예외를 이으면 틀리는 선지.
- **경쟁 쌍**: 정답과 조건 하나만 다른 오답(받았다는 사실은 다툴 수 없다 ↔ 내용이 진실이라는 점도 다툴 수 없다).
- **계산**: 참값과 선지 수치가 정수·유한소수로 떨어지게 조건을 잡는다(세로 20→60개: 15배). 거짓 선지는 참값과 다른 깔끔한 수(20배)로 쓴다. 무한소수(13.3…)는 이의 소지가 있어 쓰지 않는다.
- 정답이 가장 긴 선지가 되지 않게, 선지 길이는 평균 ±35% 안으로 맞춘다.

**11-4 어휘**
- 선지 예문은 표준국어대사전 뜻풀이 번호와 대조한다. 정답과 같은 뜻으로 읽힐 예문 금지(v2 5번 원본 ②는 사전의 같은 뜻 예문 꼴이라 복수 정답 위험이었다).

**11-5 해설**
- 바꾼 선지의 해설은 새 선지에 맞게 다시 쓴다(옛 오답 설명과 "함정" 줄은 지운다).
- 해설에 내부 메모를 두지 않는다: "(선생님…)", "[검색]", "중간고사 N번처럼…". 출처는 md의 "출처" 목록에만 둔다.

**11-6 검증과 배포**
1. `tools/import_exam.py pdf`로 앱 PDF를 문항 md로 변환(정답·해설 쪽은 자동 제외).
2. md 수정 → `tools/make_exam_multi.py`로 PDF 생성(`apt-get update && apt-get install -y fonts-nanum fonts-noto-cjk` 필요).
3. `node tools/app_parse_check.mjs <PDF>`(exam-app에서 `npm ci` 먼저): 문항 수, 정답, 단답형, **100점**, **경고 없음**을 확인한다. 쪽 그림 1~2장도 눈으로 본다.
4. 앱 추가는 `exam-app/ADD_PAPER.md`(main에 있음)대로: **main에서 새 브랜치** → PDF와 `index.json`만 커밋 → PR → 병합 → 병합 커밋의 배포 실행이 `success`인지 확인.
- 난이도는 사람이 푼 판정이 기준이다. 상향은 오류 수정을 먼저 끝낸 뒤 한다.
