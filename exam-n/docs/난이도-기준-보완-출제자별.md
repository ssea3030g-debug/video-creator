# 난이도 기준 보완 — 출제자(파트)별 L 기준

> `난이도-기준-지침서.md`(이하 기본 지침서)를 **대체하지 않고 덧붙인다.** 둘이 충돌하면 이 문서의 출제자별 기준을 쓴다.
> 근거: 중간고사 원본 PDF를 다시 측정한 값(아래 1장) + 「파트별 출제자 사고방식」. 정답률 데이터는 없다. **L은 지금도 추정**이며, 학교 정답표·정답률을 받으면 바로 보정한다.
> ※ 「파트별 출제자 사고방식」의 법 파트 `L1~L8`은 **오답 제작 기법 번호**이지 난이도 L이 아니다. 헷갈리지 않게 이 문서에서는 기법을 `법-기법1~8`, 난이도를 `L1~L4`로 쓴다.

## 0. 기본 지침서의 빈틈 (원문을 다시 보고 알게 된 것)
1. **"근거 지점 수"만으로는 배점이 설명되지 않는다.** 예술 28번(선지 15~24자, 진술×학자 조합)이 3.3점, 과학 22번(어휘, 선지 13~24자)이 3.2점인데 근거 지점은 적다. 반대로 법 11번(2.4)·15번(2.6)은 선지가 짧고 근거도 한두 곳이다.
2. **출제자 네 명의 배점 눈높이가 다르다.** 같은 "3.0"이 인문에서는 보통 수준이고 법에서는 가장 어려운 축이다(1장).
3. **선지 길이는 난이도 지표가 아니라 출제자의 문체다.** 길이는 출제자별로 맞추고(인문 82 / 법 60 / 과학 63 / 예술 37~47), 난이도는 아래 축으로 잰다.

## 2. 보완된 L 정의 — 다섯 축 점수제
문항마다 아래 다섯 축을 0~2점으로 매기고 합으로 L을 정한다. 기본 지침서의 "근거 지점 수"는 A축이 된다.

| 축 | 0 | 1 | 2 |
|---|---|---|---|
| **A 근거 지점** | 지문 한 문장 | 지문 두 곳, 또는 <보기> 1 + 지문 1 | 세 곳 이상, 두 지문 통합, 외부 이론 |
| **B 소거 저항** (지문 없이 틀린 줄 아는 오답 수) | 2개 이상 | 1개 | 0개 (오답 4개 모두 지문을 봐야 틀림) |
| **C 변조 은밀도** | 낱말·극단어 교체 | 한정어(방향·정도·조건) 한 군데 | 앞절 참 + 뒷절 거짓, 이중부정·양보절 위장, 다른 제도·학자의 참말 |
| **D 정보 변환** (<보기>→지문 매핑) | <보기> 없음 / 지문 어휘 그대로 | 상황을 지문 용어로 번역 | 이름표 없는 수치·표·날짜를 스스로 판정 |
| **E 연산·조합** | 없음 | 단순 조합(ㄱ~ㄷ 짝짓기), 날짜 1회 계산 | 2단계 계산, 두 변수 동시 변경, 진술×학자 조합 |

| 합 | 단계 | 사용 |
|---|---|---|
| 0~2 | **L1** | 세부 일치. 한 세트에 많아야 1개 |
| 3~4 | **L2** | 기본 추론·단순 <보기> |
| 5~6 | **L3** | 변별 문항 |
| 7~10 | **L4** | 세트당 최대 1개(최상 목표 시 세트당 1~2개) |

- **최상 목표 규칙**: 한 세트의 L 합산이 중간고사 같은 번호 문항의 합산 이상이어야 한다. L3·L4가 전체의 55% 이상(중간고사 3.0↑가 45%이므로 +10%p).
- **금지(기본 지침서 유지)**: 복수 정답, 모호함, 3단계 이상 계산, 극단어 오답 2개 이상. L을 올리는 방법은 **B·C축**이지 A·E축 무한 증가가 아니다.
- 배점은 L의 결과다. 출제자별 배점 눈높이(3장)로 환산하되 점수를 목표로 쓰지 않는다.

## 3. 출제자별 L 기준·배점 환산

### 3-1. 인문 (평균 2.90 · 학자 "어디까지" 주장했나)
- **A 올리는 법**: 한 문항에서 학자 둘 이상의 입장을 한 <보기> 안에 심는다(4번 3.3: 3지문 통합 + 종합 견해, 3번 3.2: <보기> A·B × 지문 개념).
- **B 올리는 법**: 학자 귀속 바꾸기를 오답 한 개 이하로 두고(너무 눈에 띔), 나머지는 방향·정도·시간 한정어(H4)로 만든다. 비판받는 기존 견해에도 선지 하나(H8).
- **C**: 참 선지를 이중부정·완곡 표현으로(H7). "일부 수용"이 정답인 종합 견해형(H2).
- **D**: <보기>는 서사, 지문 어휘를 그대로 심는다(H9: 앞절 <보기>, 뒷절 지문). D는 1이 한계.
- **배점 환산**: L1 2.5 / L2 2.7~2.9 / L3 3.0~3.2 / L4 3.3. 선지 길이 평균 80~86자.

### 3-2. 법 (평균 2.67 · 낮고 좁다 · 조건이 핵심)
- **배점 환산이 다르다**: 일치 문항도 "조건+결론" 선지라 L1이어도 2.4~2.5. **L3가 2.9~3.1이고 3.2 이상은 쓰지 않는다**(원본 최고 3.1). 법에서 3.3을 주면 출제자 눈높이를 벗어난다.
- **A**: 요건 + 날짜 + 사례 3개를 엮는다(13번 3.1).
- **B 핵심 레버**: 숫자 선지는 모두 참으로 계산 가능하게, 틀린 선지는 숫자 없는 개념 서술(법-기법4). 요건 하나만 바꾼 오답(법-기법2), 다른 제도의 참인 문장(법-기법5).
- **C**: 같은 한정어 "~해야만"을 참 선지와 거짓 선지에 한 번씩(법-기법1). 반대편 당사자 입장(법-기법3).
- **D**: <보기>는 날짜·등기부·갑을병(1단계 번역). 지문에 없는 법률어를 오답에 심기(법-기법8).
- **E**: 날짜 1회 계산까지. 선지 길이 평균 55~64자. 법이 아닌 사회 지문에는 이 틀을 쓰지 않는다.

### 3-3. 과학·기술 (평균 2.98 · 3.0↑ 3분의 2 · 단계가 핵심)
- **배점 환산**: 가장 높게 준다. L2 2.6~2.9 / L3 3.0 / L4 3.3. 계산·조건 문항(20·24번)이 3.3.
- **A·E 중심**: 수치는 참으로 깔고 마지막에 두 변수를 동시에 바꾼다(S6). 표·수치 <보기> 한 개가 곧 L3.
- **B**: 한 낱말 교체(S1)·단계 이동(S2)·그럴듯한 가짜 기제 — 오답 4개가 모두 다른 기법이어야 B=2.
- **C**: 양보절이 붙은 참 선지(S9), 지문 끝 부가 정보에 없는 인과(S12), 비대칭 추론(S5).
- **D 핵심**: 이름표를 지우고 수치만 준다(S11, 19번). 인문<법<과학 순으로 숨긴다.
- **어휘 문항**: 근접 뜻풀이(S10)로 사전 대조가 필요해야 3.2(22번). 선지는 13~24자로 짧아도 된다.

### 3-4. 예술 (평균 2.95 · 짧은 선지, 높은 배점)
- **배점 환산**: 선지가 짧아서 B·C에 모든 난이도를 건다. 진술×학자 조합(28번 3.3), 실존 외부 이론 분류틀(27·33번 3.1~3.2).
- **A**: 외부 이론(실존 이론가)을 분류틀로 얹는다(예술-기법2). 지문 안만으로는 풀리지 않게.
- **B**: "A와 달리 B는"의 전제를 거짓으로(예술-기법1). 소거로 풀리는 조합형(예술-기법3)은 오답 2개가 눈에 띄기 쉬우니 단독 정답으로 쓰지 않고 한 세트에 1개까지.
- **C**: 앞절 참 + 뒷절 거짓, 인물 교체(예술-기법4).
- **어휘**: 다의어 예문(29)·구절 바꿔 쓰기(32). 선지 짧게(14~26자), 단어 한 개만 바꾼다.
- 선지 길이 평균 37~47자(어휘 제외). **인문처럼 길게 쓰지 않는다.**

## 4. 모의고사 적용 규칙
1. 문항마다 **출제자(파트)를 먼저 정하고**(지문이 철학·사상=인문, 법·제도=법, 과정·장치=과학, 예술이론=예술) 3장의 길이·배점 환산을 쓴다.
2. 다섯 축을 점수로 적어 해설 끝줄에 `난이도: L3 (A2 B1 C1 D1 E0, 합5)` 형식으로 쓴다.
3. 세트 안 L 분포는 L1 ≤ 1개, L3~L4 ≥ 55%. 같은 출제자 내에서 같은 기법 반복 금지.
4. 검증: 소거 저항(B)은 "지문을 가리고 풀었을 때 정답이 서는가"로 판정한다. 서면 B=0으로 낮추고 재작성한다.
5. 한계: L 판정은 여전히 추정이다. 학교 정답표·정답률이 들어오면 3장 환산표만 수정한다.
