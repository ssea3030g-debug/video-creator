## 모의고사 제작 시 수정 사항 (v2 제작하며 정한 것, 2026-11-16)

### 1. 전체 체제
- 9세트, 선택형 33문항 + 단답형 2문항 = 35문항, 100점 (선택형 95점 + 단답형 5점). 중간고사와 같다.
- 지문 배열 순서: 인문 → 사회 → 과학·기술 → 예술.
- 단답형은 시험지 맨 끝에 모으지 않는다. 해당 지문의 선택형 문항 바로 뒤에 둔다. 세트 지시문에 "[6~9, 단답형 1]"처럼 함께 적는다.
- 시험지 분량은 중간고사처럼 14쪽 안팎으로 맞춘다.

### 2. 세트 구성 (v2 기준)
| 세트 | 번호 | 지문 |
|---|---|---|
| 1 | 1~5 | (가) 니체 힘에의 의지 / (나) 기억과 망각 |
| 2 | 6~9, 단답 1 | (가) 후설 / (나) 메를로퐁티 / (다) 레비나스 |

### 3. 지문은 원문만 쓴다
- 원본에 없는 지문을 새로 써서 (나)로 붙이지 않는다.
- 계산에 식이 필요하면 해당 문항의 <보기> 안에 짧게 넣는다. 예: 21번 <보기>에 C = ε × A/d, 상호 정전 T = M × N × t₀, 자기 정전 T = (M + N) × t₀, 갱신 횟수 = 1초 ÷ T.

### 4. <보기> 문항 수
- 중간고사는 33문항 중 <보기> 문항이 16개였다(3.0점 이상 15문항 중 12개). 모의고사도 16개 안팎으로 맞춘다. 너무 많으면 안 된다.
- 한 지문에 <보기>가 몰리면 하나를 일반 추론이나 어휘 문항으로 바꾼다.
- 선생님이 언급한 <보기>(백내장, 이독제독)는 남긴다.

### 5. 배점
- 2.4~3.3점으로 넓게 나눈다. 3.0점 이상 15문항(그중 3.1~3.3점 11문항).
- 3.3점은 3지문 종합, 계산형, 농도·조건 실험형 같은 최고난도 문항에 준다.
- 사전적 의미 문항은 3.2점.

### 6. 어휘 문항은 선생님이 직접 지은 선지로 만든다
중간고사 어휘 문항은 사전 뜻풀이를 그대로 옮기지 않고, 선생님이 선지를 직접 지어 "아닌 듯 맞는 듯" 헷갈리게 냈다. 모의고사도 이렇게 만든다.
- 사전적 의미(중간 22번형): 발문은 "가장 적절한 것". 정답 하나만 사전 뜻풀이이고, 나머지는 한 단어만 바꾸거나(다시→처음으로, 가로→세로), 주체를 뒤집거나(속여 넘김→속아 넘어감), 비슷한 말의 뜻풀이(방치·확산)를 넣는다. 소리가 같은 한자어(産出/算出)도 함정으로 쓴다.
- 문맥 풀이(중간 16번형): "문맥을 바탕으로 ⓐ~ⓔ를 이해한 것으로 적절하지 않은 것은?" 선지는 "~라는 의미로 쓰였다"를 직접 쓴다. 틀린 선지는 비슷해 보이는 다른 뜻으로 바꾼다(억제 → 느리게 전달됨, 일탈 → 포기).
- 다의어(중간 29번형): 같은 단어의 다른 뜻 예문 4개를 직접 짓는다. '눈앞에 보이다'처럼 가장 그럴듯한 다른 뜻을 매력적 오답으로 둔다.
- 구절 바꿔 쓰기(중간 32번형): 밑줄 구절을 그것이 가리키는 인물·개념으로 바꿔 쓰고, 오답은 인물을 바꾼다(흄 → 플라톤). v2에는 아직 없음. 넣으면 어휘 4문항이 된다.
- 단어 동의어 바꿔 쓰기(포획→사로잡기 식)는 중간고사 방식이 아니므로 쓰지 않는다.
- 뜻풀이는 표준국어대사전과 대조해 확인한다.

## 문항 아이디어 비축 (다음 회차에 쓸 것)

### 차선의 이론 — 사회무차별곡선의 '가중치'를 효용 공간 <보기>로 (2026-11-18, 사용자 질문에서 나옴)
- 지문 근거: 4문단 "우하향할수록 기울기가 완만 ← 높은 효용에 낮은 가중치, 낮은 효용에 높은 가중치(공평성 가치판단)". 지문 <그림>은 쌀·옷 축이라 가중치가 그림에 직접 드러나지 않는다 → 학생이 실제로 헷갈린 지점.
- 문항 틀: <보기>에 가로축 '갑의 효용', 세로축 '을의 효용'인 사회무차별곡선과 두 점(갑이 잘사는 점 P, 을이 잘사는 점 Q)을 준다. 지문 4문단의 가중치 설명을 적용해 판단하게 한다(적용형, 3.0점 안팎).
  - 정답 방향: P(오른쪽 아래)에서 을의 효용 1을 줄이면, 같은 사회후생을 유지하려면 갑의 효용이 1보다 많이 늘어야 한다 → 곡선이 완만.
  - 오답 기법: ① 가중치 방향 뒤집기(잘사는 쪽에 높은 가중치), ② P와 Q의 기울기 맞바꾸기, ③ '원점에서 멀수록 후생↑'을 곡선 '위의 점끼리' 비교에 잘못 적용(같은 곡선 위는 후생 동일), ④ 효용 공간 곡선의 기울기를 생산가능곡선(효율성)과 혼동, ⑤ 지문 <그림>의 쌀·옷 축에 가중치를 그대로 대응.
- 주의: 효용 공간 그림은 지문 밖 내용이므로 <보기>에서 축과 전제를 완결해서 제시한다(지문만으로 풀리게). 숫자를 쓰면 1단계 비교까지만(계산 3단계 금지).
- 단답형 변형 가능: "P에서 곡선이 완만한 것은 ( ㉠ ) 효용수준을 누리는 사람의 효용에 높은 가중치를 주기 때문" → 낮은.
