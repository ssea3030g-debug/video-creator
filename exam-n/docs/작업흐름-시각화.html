① 모의고사(9세트·33문항) 따라갈 순서

0. ★최우선 원칙정답이 한눈에 보이면 실패. 지문은 원문 그대로(띄어쓰기만 복원).
▼
1. 세트 구성 (8-3)지문별로 문항 배치: 전개방식 → 세부 내용 → 추론 → <보기> 적용 → 어휘/단답형. 법=날짜 사례, 과학=수치 표, 2지문=융합 <보기>.
▼
2. 난이도·배점 (난이도 기준 지침서)L1 2.4–2.5 / L2 2.6–2.9 / L3 3.0–3.2 / L4 3.3 — 근거 지점 개수로 결정. 배점은 결과이지 목표가 아님.
▼
3. 선지 작성 (8-4, 12장)인문 평균 80–86자 · 전개방식/종합 ≈100자 · 선지 길이 평균 ±35% · 극단어 오답 ≤1 · 복수정답 금지 · 계산 2단계 이하.
▼
4. 오답 기법 (4장 6종)한 문항의 오답 4개는 서로 다른 기법으로. 3-1: 공통점은 맞게, 차이점에서 틀리게.
▼
5. 배치 (11-2)선지의 지문 순서 3:2 / 2:3 섞기 · 교차 선지는 ④⑤ · 정답이 가장 긴 문항 ≤ 40% · 정답 위치 고르게.
▼
6. 검증 (경량 모드)스크립트: 길이 · 분포 · 극성 · 배점 / 무료 모델 블라인드 풀이 최대 1회 / 어휘 사전 확인 / 날짜·수치 계산 재검산. 서브에이전트 기본 금지.
▼
7. 해설첫 줄 = 근거 지점 → 마지막 줄 "난이도: L? (…)".
▼
8. 빌드·저장make_exam_multi.py → PDF(문제+정답표+배점표+해설) → 작업 브랜치에 커밋·푸시 (main은 요청 시에만).

② n제(지문 1개 → 4~5문항) 따라갈 순서

1. 지문 확정원문 추출 → build_passage.py로 글자 동일성 검증. 복합 지문이면 (가)+(나) 연결 소재 정하기.
▼
2. 문항 배분 (4~5개)전개방식/내용일치 1 · 추론 1 · <보기> 적용 1~2 · 어휘 또는 단답 1. L2~L4 골고루.
▼
3. 작성 → 같은 규칙 적용위 ①의 3~5단계(길이, 오답 기법, 배치)를 그대로.
▼
4. v2 비교 점검v2 같은 유형 문항과 선지 길이·근거 개수·함정 수준 비교. 정답이 보이는 문항은 재작성.
▼
5. PDFmake_exam_pdf.py (단일 세트 v2 양식) → 커밋·푸시.
