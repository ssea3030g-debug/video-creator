## 1쪽 머리말

- 안내 박스: 반·번호·이름·과목코드(01) 입력 / 선택형 33문항(01번~33번), 단답형 2문항 / 단답형 답은 OMR카드 앞면에 검정색 볼펜으로 작성.

## 세트(지문 묶음)
- 지시문: `[1~5] 다음 글을 읽고 물음에 답하시오.` / 단답형 포함 시 `[6~8, 단답형 1] 다음 글을 읽고 물음에 답하시오.`
- 지문은 **테두리 박스**, (가)(나)(다) 구분, 단락 첫 줄 들여쓰기. 밑줄 친 어휘에 ⓐ~ⓔ(또는 ㉠~㉢) 표시(굵게+밑줄).
- 지문은 단 사이를 넘어 이어진다.

## 문항
- `번호. 발문 [배점점]` 한 줄(길면 줄바꿈). 배점은 소수 한 자리(2.4~3.3). 부정형 발문의 **"않은"에 밑줄**.
- 발문 예: `(가)~(다)에 대한 설명으로 가장 적절한 것은?` / `~적절하지 않은 것은?` / `윗글을 바탕으로 <보기>의 …을 이해한 내용으로 …` / `문맥상 ⓐ~ⓔ와 바꿔 쓰기에 적절하지 않은 것은?`
- `<보기>`: 테두리 박스, 제목 `< 보 기 >` 가운데, 박스 안은 한 사례·상황·학자 A/B 견해 등.
- 선지 ①~⑤: 줄마다 하나, 긴 서술형(자료 `<보기>` 문항 선지 길이 길게). **어휘 문항 선지는 짧게**(예: `① ⓐ: 도덕적 시민을 양성하기 위한 미술`).
- 문항 사이 여백 넉넉(문항이 단 하단에서 끊기지 않게 단 이동).

## 단답형
- `[단답형 1] 윗글을 바탕으로 <보기>의 빈칸에 들어갈 말을 지문에서 찾아 각각 3음절로 쓰시오. [2점, 각 1점]` + `<보기>` 박스 + 답란 `㉠: (        ), ㉡: (        )`.
- 해당 지문의 선택형 문항 바로 뒤에 둔다(맨 끝에 모으지 않음).
