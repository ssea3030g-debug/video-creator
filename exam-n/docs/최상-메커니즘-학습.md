# '최상' 메커니즘 학습 노트 (Gemini 분석 + 검토, 2026-11-17)

> 입력: 중간고사 원본, v2, v3(2차 보완본), v4(2차 보완본) PDF 텍스트. 사용자 판정: 중간고사·v2·v4 = 최상, v3 = 상.
> 원문 분석: `docs/gemini-분석/`(시험지별 4개 + 종합 1개).
> **한계:** gemini-3.5-flash가 과부하(503)·한도(429)로 실패해 전부 **flash-lite**가 분석했다. lite는 독자 판정에서 중간고사를 '상', v3를 '최상'으로 매겨 사용자 판정과 어긋났다. 정답·해설 쪽의 "L4" 같은 자기 평가 문구에 끌린 것으로 보인다. 그래서 아래는 lite의 종합을 그대로 믿지 않고, 원문 문항으로 확인되는 것만 남겨 다시 정리했다.

## 1. '최상'을 만드는 메커니즘 (중간고사·v2·v4 공통)

| M2 | (가)+(나) 메커니즘 결합 <보기> | 두 지문의 원리를 한 대상에서 동시에 통과해야 정오가 갈림 | 중간 20(열펌프 건조기), v4 26 |

## 2. v3가 '상'에 머무는 이유 (같은 지문군 v2 대비)
1. **계산·조건 문항의 압박이 한 단계 낮다.** v2 12번(배당)·21번(정전 용량 + 덮개 두께 변경)에 비해 v3 12·21번은 변수 연동이 적다(2차 보완에서 일부 복원).
2. **한 문장 대조로 풀리는 선지가 남아 있다.** v3 1·18번(전개 방식), 31번 일부.
3. **오답 기법이 '앞절 참 + 뒷절 거짓'에 쏠려 있다(lite 추정 약 45%).** v2·v4는 이중 부정, 직관값, 조건 변조가 더 고르게 섞여 있다.
4. **어휘 문항(5·25·30)이 지문 기전과 떨어진 독립 측정에 가깝다.**
5. **외부 이론·융합 문항은 들어갔지만(9·22·29) 선지끼리의 얽힘이 v2 4번 수준에 못 미친다.**

## 3. 다음 회차를 처음부터 '최상'으로: 체크리스트
(lite 종합안에서 근거가 약하거나 원본과 어긋난 항목은 고쳐 적었다.)
1. M1 다지문 종합 평가 1문항 이상(인문).
2. M2 (가)+(나) 결합 <보기>: 복합 지문 세트마다 1문항.
3. M3 외부 이론 <보기> 2문항 이상.
4. M4 서식·시계열 문항: 법 세트에 1문항 이상. 날짜 선지만 참인 패턴을 반복하지 않는다.
5. M5 계산 + 조건 변경 2문항 이상, 오답에 직관값 1개 이상.
6. M6 비대칭·방향성 추론 1문항(과학).
7. 참 선지 위장(이중 부정·양보절) 3문항 이상.
8. 오답 기법 분포: 앞절 참 + 뒷절 거짓은 **40% 이하**로 묶는다. 개념 맞바꿈·귀속 교체, 조건 변조, 인과 역전, 직관값을 고르게 섞는다. (lite는 "45% 이상 유지"를 권했지만 원본 중간고사는 30% 안팎이고, v3의 약점이 바로 이 쏠림이라 반대로 적용한다.)
9. 한 문장 대조로 즉시 소거되는 선지는 문항당 1개 이하. 일치형(L1)은 회차당 3문항 이하. (원본 중간고사에도 9·21번 같은 일치형이 있으므로 '0개'를 강제하지 않는다.)
10. 어휘 문항은 지문 기전과 연결되는 단어를 고르고, M8 방식으로 변조한다.
11. 전개 방식 문항은 '구조는 같고 장치가 다른' 짝을 정답으로(H5). 공식형 선지("A와 달리 B는")만으로 소거되지 않게 한다.
12. 단답형은 사례 추론형(지문 개념 + <보기> 인물), 음절 힌트 금지.
13. 분석·검증에 쓰는 문서에 자기 평가 문구(L4 등)를 넣은 채 외부 모델에 맡기지 않는다. 판정이 끌려간다. 문제지만 넘긴다.

## 4. 바로 적용할 일 (제안)
- v3: 1·18번 전개 방식 문항을 H5형으로 교체하고, 어휘 25·30번을 기전 연결형으로 바꾼다. 오답 기법을 문항별로 표시해 앞절/뒷절 비율을 40% 이하로 맞춘다.
- 재분석: gemini-3.5-flash가 회복되면 **문제지만**(해설 제외) 넘겨 다시 판정받는다.
