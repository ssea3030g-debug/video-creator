# 지침 압축본 색인 (exam-n/guide)

원문 지침서 약 150KB를 제작·검수에 필요한 규칙만 남겨 약 64KB로 줄인 **기준 문서 세트**다. 원문은 `docs/`(현재 `claude/vibrant-einstein-iskm3i` 브랜치)에 그대로 있고, 압축본의 해당 절 번호는 원문과 같다.

| 파일 | 합친 원문 | 크기 |
|---|---|---|
| `01-출제원칙-제작공식.md` | 출제분석 지침서 (★최우선 원칙, 0, 1-3·1-4, 3~5, 8, 10, 11-2, 12-5) | 19KB |
| `02-파트별-출제틀.md` | 파트별 출제자 사고방식 | 13KB |
| `03-난이도-기준.md` | 난이도 기준 지침서 + 보완 | 9KB |
| `04-모의고사-체제.md` | 모의고사용 지침서 + 출제분석 14장(선생님 메모) | 5.5KB |
| `05-실수-유의사항.md` | 실수 유의사항(번호 유지) + v6 검수에서 추가 8개 | 6.8KB |
| `06-최상-메커니즘.md` | 최상 메커니즘 학습 | 3.8KB |
| `07-편집형식.md` | 출제분석 13장 + 중간고사 편집형식 | 3KB |

제작 때는 이 세트 대신 한 장짜리 **`../core/핵심-틀.md`**만 읽는다. 이 세트는 사용자가 "지침 검수"를 요청할 때 기준으로 쓴다(`../core/작업-흐름.md` 3단계).

## 원문에서 뺀 것 (필요하면 원문의 같은 번호 절을 연다)
- 출제분석 지침서: 1-1·1-2 세트 출처표, 2장 역설계 Step 1~6과 원본 급소 표, 6장 분야별 출제 방식(→ 02에 흡수), **7장 문항별 전수 분석표**, 9장 학습 포인트, 10-1·10-3 세트별 연결 고리·열펌프 역설계 본문, 11-1·11-3·11-4 전수 배분표, 12-1~12-4 길이 통계, 13-5 HWP 설정 표, 14장.
- 파트별 사고방식: 각 틀의 "관찰" 서술(문항 번호 인용), 6장 근거 약한 부분.
- 난이도 기준: 중간고사 실측 분포 상세, 고친 사례 표(01에 있음).
- 모의고사용 지침서: v2 세트 구성 표.
- 최상 메커니즘: lite 분석 한계 서술, "바로 적용할 일"(v3 수정 계획).
- 기타 원문은 그대로 있다: `WORKFLOW.md`(→ `../core/작업-흐름.md`가 대체), `docs/gemini-분석/`, `docs/이전대화-공유본.md`, 해설지, v2 원문.

## 지침끼리 충돌할 때의 기준 (정리 결과)
| 충돌 | 정리 | 근거 |
|---|---|---|
| 단답형: 출제분석 8-6·3-7 "음절 수 지정·출처 지정" vs 실수 20 "음절 힌트 금지" | **음절 힌트 금지, 사례 추론형.** 앞뒤 문맥이 개념 하나만 가리키게 | 실수 2·20 (사용자 채택) |
| 난이도: 기본 지침서 "근거 지점 수" vs 보완 "다섯 축" | **다섯 축 점수제**, 출제자별 배점 환산 | 보완 문서 머리말 |
| 3.3점 개수: 출제분석 "4개 안팎" vs 최상 목표 "L4 9~10문항" | 배점은 L의 결과. 최상 목표 회차는 L4 목표를 따르고, **법 파트는 3.2점 이상 금지** | 난이도 보완 3-2, 실수 10 |

| 법 틀 적용 범위 | 법 지문에만. 경제·독점·정치 지문에는 쓰지 않음 | 사고방식 4-3 |
| 편집: 출제분석 13장 vs 중간고사-편집형식 | 07에 통합. 쪽 구성은 같고 시험지 수치는 13장 기준 | — |
