## ★ 최우선 원칙: 정답 선지가 "보이면" 실패다
정답이 지문 한 문장을 옮겼거나 오답이 극단어로 티 나면, 지문을 깊이 읽지 않고 소거만으로 풀려 중간고사보다 쉬워진다. 다른 규칙보다 먼저 지킨다.
1. **"가장 적절한 것"의 정답은 지문 문장을 옮기지 않는다.** 떨어진 두 문장, 또는 <보기> 조건 둘을 이어야 참이 되게 쓴다. (23번 ① 흥분 한계 + 위치 정보 / 24번 ① 곡선 모양에서 비대칭 도출)
2. **"적절하지 않은 것"의 정답은 '앞절 참 + 뒷절 거짓'**(또는 인과 사슬 한 고리만 거짓). "아무런·전혀·~에만" 같은 극단어나 상식으로 틀리는 내용을 정답으로 쓰지 않는다. (14번 ④ 앞절 참·뒷절 "입증 요건 완화" 거짓 / 19번 ③ 첫 고리 "온도 계속 상승"만 거짓)
3. **맞는 선지 넷도 정답만큼 그럴듯하고 길게.** 길이·어조·한정어 수를 맞춘다. 양보절("~더라도")이나 이중 부정을 붙인 참 선지를 1~2개 섞어 '수상하면 오답' 요령을 막는다.
4. **지문 없이 틀린 게 보이는 오답은 많아야 하나.** 나머지는 지문 속 다른 대상의 참말, 지문에 없지만 그럴듯한 기제, 인과 사슬의 한 고리만 바꾼 문장.
5. **학생의 실제 착각을 노린다.** 위치 순서 = 손상 순서(눈 5번), 분모 2배 = 값 절반(20번 ⑤). 학생 필기에 나온 오개념이 최고의 재료.
- 예외: 2.4~2.6점 세부 일치는 지문 문장에서 한 곳만 바꿔도 된다(9·11·17·21번). 회차당 3문항 이하.

**점검 질문 셋 (하나라도 '예'면 고친다)**
- 정답을 지문 한 문장과 맞대 보기만 해도 판정되는가? (일치 문항 제외)
- 지문 없이 틀린 게 보이는 오답이 둘 이상인가?
- 정답만 혼자 길거나 친절하거나, 반대로 혼자 극단적인가?

**파트별 적용 요약** (자세한 틀은 `02`)
- 과학·기술: 인과 사슬의 **첫 고리나 중간 고리 하나**만 틀림. 하지 말 것: 지문 용어를 늘어놓은 정답, "아무런 영향이 없다" 정답, 상식으로 틀린 오답.
- 사회(법): 날짜·용어는 참으로 깔고 **요건 하나**에서 틀림. 정답 열쇠는 표의 작은 칸·사례 수식어·단서 조항에. 하지 말 것: 정의를 그대로 옮긴 정답, 주체만 엉뚱하게 바꿔 보이는 오답 둘 이상.
- 인문·예술: 학자의 **입장 정도와 경계**에 숨김. 정답은 부분 수용, 맞는 선지는 이중 부정. 하지 말 것: 오답 넷이 모두 "오직·전적으로" 극단어 하나로 틀리는 문항(극단어 오답은 하나까지).
- 경제·정치 지문은 중간고사 근거가 없다: 계산 선지는 참으로 깔고 개념 선지에서 틀리게 하는 틀만 옮긴다.

## 0. 출제자의 핵심 방식 (요약)
1. 지문은 한 글자도 안 고치고 묶음·기호만 바꾼다(밑줄·㉠·ⓐ 위치를 원본과 다르게).
2. 원본 문항은 그대로 내지 않되 **원본의 급소(해설지의 정답 근거·오답 해설 인용 문장)는 형식만 바꿔 다시 낸다.**
3. 세트 공식: 일치(또는 전개 방식) 1 + 비교·추론 1 + <보기> 적용 1~3 + (어휘 1).
4. **변별은 <보기>에서.** 33문항 중 16개가 <보기>, 3.0점 이상 15문항 중 12개가 <보기>. 3.3점은 지문 통합·수치 계산·조건 조합.
5. 오답은 여섯 기법(4장). 단답형은 핵심 용어를 지문에서 찾아 쓰게(→ `05` 실수 20으로 개정).
6. 짝지은 지문은 다섯 방식으로 한 문항 안에서 맞물린다(10장). 선지는 지문 순서대로 3:2 또는 2:3, 교차 선지는 ④⑤(11-2).

| 유형 | 개수 | 배점대 |

| 전개 방식·글 전체 설명 | 3 | 2.4~3.0 |
| 세부 내용 일치 | 4 | 2.4~2.9 |
| 개념·제도 비교 | 3 | 2.5~2.8 |
| 추론(이유·함의) | 3 | 2.6~3.1 |
| <보기> 사례·자료 적용 | 12 | 2.7~3.3 |
| <보기> 외부 관점·진술 판단 | 4 | 3.1~3.3 |
| 어휘 | 4 | 2.6~3.2 |
| 단답형 | 2 | 칸당 1점 |
- 배점: 2.4~2.5 단일 지문 일치·단순 비교 / 2.6~2.9 추론·교차 비교·단일 지문 <보기>·문맥 어휘 / 3.0~3.2 자료 <보기>·외부 이론 <보기>·사전적 의미 / 3.3 3지문 통합·융합 장치 + 계산·조건이 붙은 실험·진술 × 학자 조합.

## 3. 문항 유형별 제작 공식
**3-1. 전개 방식·글 전체 설명** — 발문 "(가)~(다)에 대한 설명으로 가장 적절한 것은?" 선지 틀 "(가)와 (나)는 모두 [공통점]지만 (가)는 [특징] 반면 (나)는 [특징]" / "(가)와 달리 (나)는 ~". 오답: 공통점은 맞고 차이점에서 틀림 / 한 지문의 특징(사고 실험, 실제 작품)을 다른 지문에 붙임 / 통시↔공시 / 지문에 없는 전개(절충, 하나를 선택, 한계 지적). 내용을 섞어 물으면 정답은 내용 오류(마르쿠제 "이익 제공" → "이해관계와 무관")로.
**3-2. 세부 일치** — 정답은 지문 문장에 가깝게(21③, 17①~④). 틀린 선지는 **한 군데만**: 주체, 필수 여부(필요 없다→~어야만), 용어(전기→신경 신호), 수량(한 종류→여러), 위치(윗→아랫), 관계(표현할 수 없다→같이 고려).
**3-3. 개념·제도 비교** — "ⓐ와 ⓒ는 모두 ~지만 ⓐ는 ~, ⓒ는 ~" / "㉠과 달리 ㉡은 ~". 두 지문의 개념을 교차로 묶는다(7번: ⓐⓑ는 (가), ⓒⓓ는 (나) → 5개 조합). 오답: 두 개념 설명 맞바꿈, 요건 삭제, "모두" 일반화.
**3-4. 추론** — 이유 추론: 정답은 다른 문단과 연결, 오답 넷은 **지문 속 다른 대상의 이유**. 함의 추론: 맞는 전제 + 틀린 결론.
**3-6. 어휘 네 유형을 하나씩**
| 유형 | 발문 | 오답 |
|---|---|---|
| 문맥 풀이(한자어) | "문맥을 바탕으로 ⓐ~ⓔ를 이해한 것으로 적절하지 않은 것은?" | 비슷해 보이는 다른 뜻(일탈→포기·철회). 반대 뜻은 안 됨 |
| 사전적 의미 | "ⓐ~ⓔ의 사전적 의미로 적절한 것은?" | 유사어 뜻풀이, 한 단어만 바꿈(가로→세로), 주체 뒤집기, 동음 한자어 |
| 다의어 | "문맥상 ⓐ와 가장 가까운 의미로 쓰인 것은?" | 같은 단어의 **서로 다른** 뜻 예문 4개 |
| 구절 바꿔 쓰기 | "바꿔쓰기에 적절하지 않은 것은?" | 지시 내용의 인물·개념 교체(흄→플라톤) |
- 뜻풀이는 기억으로 쓰지 말고 표준국어대사전 대조. 선지를 선생님처럼 직접 짓는다(동의어 바꿔 쓰기는 쓰지 않는다).
**3-7. 단답형** — 용어 기입형, 칸당 1점, 정답은 지문에 한 번 이상 나오는 용어. (음절 수 지정은 `05` 실수 2·20으로 폐기: 앞뒤 문맥이 개념 하나만 가리키게 하고 사례 추론형으로)

## 4. 오답 선지 제작 기법 여섯 가지
| 기법 | 설명 | 예 |
|---|---|---|
| ① 주체·대상 바꿔치기 | A의 설명을 B에 붙임 | 9②(추인 주체), 7①(규율↔생명 권력), 12④(요역지↔승역지), 21①(전기↔신경 신호), 32⑤(흄→플라톤) |
| ② 방향 뒤집기 | 증가↔감소, 유지↔소멸, 엄격↔완화 | 3②(심화→완화), 7⑤(박탈→확대), 14④, 12② |
| ③ 한정어·조건 덧붙이기 | "~만으로", "~전까지는", "~어야만", "관계없이", "모두" | 2⑤, 5①, 11④, 18③, 10⑤ |
| ④ 범주 혼동 | 비슷한 다른 개념 | 21②(낮은 소리→작은 소리), 16③, 25③ |
| ⑤ 앞은 맞고 뒤가 틀림 | 맞는 근거 + 틀린 결론 | 19③, 31②, 14④ |
| ⑥ 지문에 없는 내용 | 근거 없는 기제·우선순위·절차 | 10①(통지 철회), 4⑤, 23②③ |
- 추가: **"A와 달리 B는"** — B 진술은 맞지만 A도 그러해서 틀림(27④). **계산 함정**: 분모 2배 → 절반이라는 직관(20⑤: 실제는 분자도 변해 4 → 2.5, 37.5% 감소). **"적절한 것"의 정답은 지문 표현을 한 단계 바꿔 말한다**(재진술), 오답은 지문 표현을 그대로 쓰되 한 곳을 바꾼다 — 표현이 같다고 맞는 선지가 아니다.
- 한 문항의 오답 넷은 서로 다른 기법, 틀린 곳은 정확히 한 군데.

## 5. <보기> 제작 기법
| 방식 | 설명 | 예 |
|---|---|---|
| ① 동형 사례 치환 | 구조는 같고 소재를 바꿈 | 2(아이들→영희), 3(역사서 논쟁→Z국 농민 시위), 5(금속→두 섬의 식물) |
| ② 형식 전환 | 그래프→표, 그림→흐름도, 그래프→조건문 | 19, 20, 24 |
| ③ 수치·날짜 삽입 | 계산·기간 판정 | 13, 14, 20, 23 |
| ④ 현대적 사례 | 이론 여러 개를 한 상황에 적용 | 8(스마트 공장 AI) |
| ⑤ 지문 간 융합 | 두 지문 원리가 한 장치에 동시에 | 20, 23 |
| ⑥ 외부 이론 도입 | 실존 이론을 5~6문장 요약해 틀로 | 4, 27(볼츠), 33(스튜어트 홀) |
| ⑦ 진술 판단 | ㄱ~ㄹ 진술 × 학자 조합 | 28 |
| ⑧ 실제 작품 | 작품 + 설명, 인물끼리 비평 | 30 |
- 외부 이론은 지어내지 않고 **지문 주제와 맞닿은 실존 이론**을 요약. 분야를 건너뛰기도 한다(예술 지문 + 매체 수용 이론).
- 선지 설계: 선지마다 담당 인물·개념이 다르다. 틀: "[인물]의 관점에서, [<보기> 사실]은 [지문 개념]으로 볼 수 있다". 맞는 선지는 <보기>와 지문 표현을 1:1로 잇고, 틀린 선지는 지문 개념 쪽에서 4장 기법.

## 8. 기말 문항 제작 지침 (제작 순서)
**8-1 준비**: 지문마다 해설지에서 출처·원본 문항 유형·정답 근거 문장·오답 해설 인용 문장·원본 <보기> 형식을 표로. "급소 문장" 5~8개 표시(우선순위: 단서·예외 > 비교·대조 > 수치·비례 > 정의 > 평가). 원본 밑줄 위치를 적어 두고 **그 자리를 피해** 밑줄을 친다.
**8-2 세트 구성**: 주제어·공통 원리·실제 융합 사례가 있는 지문끼리 (가)(나)로 묶고, 10-2 다섯 방식 중 엮는 방식을 먼저 정한다(과학·기술 2지문이면 과정 결합형 하나). 지문마다 단독 <보기> 1 + 통합 1. 지문 원문 수정 금지. 분야별 약 25점.
**8-3 세트당 구성**
| 세트 형태 | 문항 | 구성 |
|---|---|---|
| 단독 지문 | 3 | 일치 1 + 비교·추론 1 + <보기> 1 (또는 어휘 1) |
| 2지문 | 4~5 | 전개·일치 1 + 교차 비교·추론 1 + 지문별 <보기> 1~2 + 통합 <보기> 1 (+ 어휘) |
| 3지문 | 5 | 전개 1 + 지문별 <보기> 3 + 3지문 통합 1 |
- 33문항 기준 <보기> 16, 일치·전개 7, 비교·추론 6, 어휘 4(네 유형). 단답 2는 법·인문 지문에.
**8-4 선지 작성**: ①선지 길이는 유형별 길이대·뼈대(12-5). ②틀린 선지는 4장 기법 하나만, 한 군데만 틀리게, 오답 넷은 서로 다른 기법. ③"적절하지 않은 것": 맞는 선지 넷은 지문 재진술, 틀린 선지는 그럴듯한 앞부분 뒤에 오류. ④"가장 적절한 것": 정답은 지문 표현을 한 단계 바꿔 말하되 떨어진 두 문장·<보기> 조건 둘을 이어야 참(★ 최우선), 오답은 지문 표현을 그대로 쓰고 한 곳 변경. ⑤비교 선지는 "모두 ~지만 A는 ~, B는 ~" / "A와 달리 B는 ~". ⑥원본에서 '적절한' 선지였던 내용을 뒤집어 새 정답으로 쓰는 문항을 세트마다 하나쯤.
**8-5 <보기> 작성**: 원본 <보기>는 구조 유지하고 소재·숫자·날짜 교체, 그래프는 표·조건문으로. 법은 날짜·기간 사례, 과학·기술은 수치 표·장치 흐름도. 2지문 세트에는 융합 <보기> 하나. 예술·인문 세트 하나에는 실존 외부 이론 5~6문장. 선지 다섯이 서로 다른 인물·개념·구간을 맡는다.
**8-6 단답형**: 요약문 빈칸형 1 + 사례 판단형 1. 정답은 지문에 그대로 나오는 용어, 유사 답이 생기지 않게 조건 부여. (→ `05` 20)
**8-7 배점·정답 배치**: 세부 일치 2.4~2.5 / 비교·추론 2.5~2.8 / 단일 <보기> 2.7~3.1 / 통합·계산·외부 이론 3.0~3.3 / 사전적 의미 3.2 / 단답 칸당 1점. 합 100. 정답 ①~⑤ 각 6~7개, 연속 2문항까지. 적절/부적절 약 반반.
**8-8 검수 체크리스트**
- [ ] ★ 정답이 지문 한 문장 복사가 아니고, 지문 없이 보이는 오답이 하나 이하(점검 질문 셋)
- [ ] 정답 근거를 지문에서 짚을 수 있는가(두 문장을 잇는 경우 두 곳 모두)
- [ ] 틀린 선지가 정확히 한 군데에서만 틀리는가
- [ ] 맞는 선지에 지문에 없는 추론이 섞이지 않았는가
- [ ] 계산·날짜 문항을 직접 다시 계산했는가
- [ ] 원본 문항과 밑줄 위치·정답 선지가 겹치지 않는가
- [ ] 한 세트 안에서 같은 급소를 두 번 묻지 않았는가
- [ ] 정답 번호 분포와 발문 극성이 고른가
- [ ] 통합 문항이 두 지문을 실제로 맞물리게 하는가(한 지문만 읽어도 풀리지 않는가)
- [ ] 선지가 지문(<보기> 구획) 순서대로 놓이고 어느 지문도 빠지지 않았는가
- [ ] '모두' 공통점 오답이 한 지문에만 있는 특성을 넓힌 것인지 확인했는가
- [ ] 다섯 선지가 같은 뼈대, 길이 차이가 평균의 35% 안인가
- [ ] 정답이 가장 긴 선지인 문항이 전체 40% 정도를 넘지 않는가
- [ ] 편집 형식(`07`)을 맞췄는가

## 10. 지문 엮는 방식 (복수 지문 세트)
짝짓기 기준: "같은 질문에 다른 답을 하는가"(인문·예술) / "같은 물리 현상이 다른 장치에서 일어나는가"(과학·기술). 법은 원본 묶음 유지 + 사례를 지문별로 나눔.
| 방식 | 구조 | 예 | 제작 요령 |
|---|---|---|---|
| A. 관점 대비 | 같은 상위 질문에 대한 지문별 답 비교 | 1, 6, 7, 26 | 지문마다 "주장–근거–전개 장치(사고 실험·실제 작품·통시 흐름)" 표를 만들고, 장치를 다른 지문에 옮겨 붙여 오답 |
| B. 한 <보기> 여러 렌즈 | <보기> 하나 + 선지마다 다른 학자·지문 | 4, 8, 27, 28 | <보기>를 문장 단위로 쪼개 각 문장이 한 지문에 대응 |
| C. 병렬 구획 | <보기>를 (A)(B)·사례 1·2로 나눔 | 14, 23 | 구획마다 선지 2개 + 마지막 1개에서 교차 |
| D. 과정 결합 | 두 지문의 장치를 합친 **지문에 없는 새 대상** | 20 | 10-4 |
| E. 공통 원리 선지 | "(가)의 ~과 (나)의 ~은 모두 ~" | 18④⑤, 23⑤ | 같은 사건(응축 = 열 방출)이면 정답, 한 지문에만 있는 특성을 양쪽에 붙이면 오답 |

**10-4 과정 결합형 <보기> 제작 순서**: ①두 지문 과정을 "입력 → 단계 → 출력"으로 쪼갠다 ②**같은 물리량이 같은 방향으로 움직이는 단계**(열 흡수/방출, 신호 생성/전달, 압력 증가/감소)를 짝짓는다 ③짝지은 단계로 지문에 없는 새 장치·상황을 만든다(실제 융합 사례면 더 좋다) ④장치 이름을 X·Y로 익명화 ⑤공식 있는 지문에서 수치 조건 2~3개(합이 맞게) ⑥선지: 대응 확인 2 + 법칙 확인 1 + 계산(참) 1 + 조건 변경 계산(직관 함정) 1 ⑦같은 세트 앞 문항(추론)에 공통 원리 선지로 다리를 놓는다.
(열펌프 의류 건조기 20번: 응축식 건조기의 냉각·응축 ↔ 열펌프 증발기의 흡열, 가열 ↔ 응축기의 방열. 상변화 이름이 서로 반대라 헷갈리는 지점을 중심에 둠. ⑤ "전기 에너지만 2배 → COP_H 50% 감소"는 직관, 실제 (300+200)/200 = 2.5.)

## 11-2. 선지 배분 규칙
1. **선지는 지문 순서대로.** (가) 관련 선지가 먼저. 예외는 학자 조합형(27, 28).
2. **비율은 3:2, 2:3 기본**(3지문이면 2:1:2). 한 지문이 선지 한 개만 맡을 수는 있어도 아예 빠지지 않는다.
3. **교차·공통 선지는 ④⑤**. 마지막 선지가 가장 긴 문항이 12/33인 이유.
4. 정답이 특정 지문에 몰리지 않게 (가) 정답, (나) 정답, 교차 정답을 섞는다.
5. **'모두' 공통점 선지는 오답일 때가 더 많다**(14개 중 맞는 것 6, 틀린 것 8). 틀린 쪽은 한 지문에만 있는 특성을 '모두'로 넓힌 것.
6. 밑줄 기호도 두 지문에 나눠 친다(2:2, 3:2).
- <보기> 구획 배치: 구획 2~3개, 구획마다 선지 1~2개, 마지막에 교차 1개. (예: (A)/(B): ①② (A), ③④ (B), ⑤ 교차 / 사례 1·2: ①② 사례 1, ③④ 사례 2, ⑤ 둘 다 / 장치 X·Y + 조건: ① 계산, ② X, ③ 법칙, ④ Y, ⑤ 조건 변경 계산)

## 12-5. 선지 길이 규칙
- 전체 평균 약 60자(공백 제외), 한 문항 안 최장·최단 차이는 평균의 35% 안.
- 길이대: 어휘·진술 조합 9~24자 / 세부 일치·이유 추론·단문 추론·외부 관점 40~55자 / 사례·자료 <보기>·학자 관점·2지문 설명 60~90자 / 3지문 전개 방식·종합 <보기> 약 100자. 세트 평균은 인문 80~86, 법·과학·기술 55~64, 예술 35~47.
- 뼈대를 먼저 정하면 길이가 맞는다. **한 문항의 다섯 선지는 같은 뼈대.**
- 정답이 가장 긴 선지인 문항은 원 시험에서 42%(1·2위 67%). 재현하되 **40% 안팎으로 제한**해 길이로 찍기를 막는다. 교차·종합 선지를 ⑤에 둘 때가 많으나 정답 번호 분포가 우선.
