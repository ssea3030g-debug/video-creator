# 02. 파트별 출제자 틀 (압축본)

> 원문: `docs/2026-2학기-중간고사-파트별-출제자-사고방식.md` (42KB). 레시피·체크리스트만 남기고 "관찰" 서술(문항 번호 인용)과 6장(근거 약한 부분)은 줄였다. 틀 번호(H·법 L·S·A)는 원문과 같다. 근거가 필요하면 원문의 같은 번호 절을 연다.
> **난이도 L과 헷갈리지 않게 법의 L1~L8은 `법-기법1~8`로 쓴다**(난이도 보완 문서 방식).
> 한 파트의 틀을 다른 파트에 쓰지 않는다(예: 법의 요건 흔들기를 인문 학자 입장에 쓰면 어색). 예술은 인문 선생님 출제로 추정(7:3), 뼈대는 인문 틀 + 예술 고유 틀 + 짧은 선지.

## 1. 세 파트 한눈에
| | 인문 | 사회(법) | 과학·기술 |
|---|---|---|---|
| 가려내려는 학생 | 학자 입장을 찬성/반대로만 외운 학생 | 요건만 외우고 주체·단서를 놓친 학생 | 용어·수치는 외웠지만 단계·한계를 못 따라가는 학생 |
| 지문을 읽는 눈 | 누가 무엇을 **어디까지** | 누가 **어떤 조건에서** 무엇을 | **어느 단계**에서 무엇이, 어디까지 가능한가 |
| 오답 주력 | 방향·정도 변조 + 학자 귀속 바꾸기 | 요건 변경 + 제도 맞바꿈 | 한 낱말 교체 + 단계 이동 + 가짜 기제 |
| 정답 모양 | 정도가 조절된 문장 | 조건과 결론이 맞물린 문장 | 두 문장을 합친 재진술 또는 계산 결과 |
| <보기> | 사람이 말하고 행동하는 서사 | 날짜·등기부·갑을병 | 표·수치·실험 조건·단서 |
| 선지 길이 | 80~86자 | 55~64자 | 55~64자 |
| 말끝 | ~겠군(학자 관점) | ~겠군(사례 적용) | ~때문이다(인과) |
→ **인문은 "정도"를, 법은 "조건"을, 과학은 "단계"를 흔든다.**
- 참 선지를 수상하게 꾸미는 방법이 파트마다 다르다: 인문 이중 부정(H7), 법 한정어 "~해야만"을 참 선지에도(법-기법1), 과학 양보절(S9).
- <보기>에 지문 용어를 숨기는 정도: 인문(지문 어휘를 심음) < 법(상황으로 풀어 씀) < 과학(이름표 지우고 수치만).
- 정답이 느슨하고 오답이 확실한 문항(9①, 18④, 27⑤, 28④)은 따라 하지 않는다.

## 2. 인문
**머릿속 한 줄**: "철학자는 한 문장으로 요약되지 않는다. 인정하는 부분과 부정하는 부분의 경계를 아는지 본다."
- **H1 양면 입장을 두 선지에** — 학자가 인정하는 문장 1 / 부정하는 문장 1을 뽑아, 참 선지 둘에 각각 <보기> 사례로 적용(정도어 "직접·결정적·~만으로"로 강도 맞춤). 오답 하나: 학자 입장에 **상대 학자의 결론**을 "~만으로" 단정으로 붙임.
- **H2 종합 견해 <보기>** — 3~4문장, 문장 하나는 두 학파 요소를 섞음. 선지는 학파별 평가문 1개씩(5개), 정답만 '일부 수용'("일부 받아들이기 어렵겠군"), 오답은 오직/에만/결정/우선 삽입. 요령 차단: 오답 하나는 "일부"를 쓰되 **부분의 이유를 틀리게**.
- **H3 개념 소진·조합 열거** — 개념표(개념/정의/방향/담당 학자), 선지 수를 개념 수에 맞춤(개념 4개면 6가지 짝 중 5개), 한 선지는 두 개념 설명 맞바꿈, 나머지는 방향 한 군데 반전. <보기> 서사의 사건 하나에 개념 하나, 마지막은 반전(비판자 배척). 급소 문장 하나에 선지 하나(같은 개념이 두 선지에 나올 수 있음).
- **H4 방향·정도·시간 한정어를 한 군데만** — 변조 목록: 방향 뒤집기(심화→완화, 이익 제공→무관), 시간 조건("밝혀지기 전까지는"), 범위 한정("그치는·오직·~에만·~만으로"), 설명 맞바꿈. 위치는 대부분 **뒷절**. 참 선지를 먼저 쓰고 뒷절 한 곳만 바꾼다.
- **H5 전개 방식은 "구조는 같고 장치가 다른" 짝이 정답** — 지문마다 구조·장치(사고 실험/사례/계보/대립 비교) 표 → 오답: ① 유사 짝 정답 ② 장치 이동(한 지문의 장치를 다른 지문에) ③ 주제 맞바꿈 ④ "모두" 과잉 ⑤ 한정어("그치는"). **지문에 없는 전개만으로 오답 넷을 채우지 않는다.**
- **H6 <보기> 소재·단답형** — 소재 치환(아이→영희, 역사 논쟁→Z국 시위, 금속→두 섬 식물, 감시→스마트 공장), 지문 속 두 사례를 한 인물로 합성. 단답: 앞뒤 문맥으로만 가려지는 혼동어를 빈칸으로(음절 수 힌트는 쓰지 않음, `05` 실수 2·20).
- **H7 참 선지를 이중 부정·완곡 표현으로** — "A를 B의 근거로 인정하지는 않는다", "~만으로 ~라고 할 수는 없다". 참 선지 5개 중 1~2개. 틀린 선지는 긍정 평서문으로 매끄럽게.
- **H8 비판받는 기존 견해에도 선지 하나** — 참이면 기존 견해 논리를 <보기>에 그대로 적용, 거짓이면 새 견해 요소(전문가, 외부 대상)를 섞음.
- **H9 앞절은 <보기>, 뒷절은 지문** — "[<보기> 사실]은 [지문 개념]으로 볼 수 있다". 앞절은 <보기>를 복사(항상 참), 뒷절만 H4 변조. 앞절에서 틀리게 하지 않는다.
- **체크리스트**: 학자 귀속 확인 / 정답이 지문 문장 번호로 1:1 연결 / 오답이 방향·정도·시간·범위 중 **하나만** 바뀜 / 선지 80자 안팎, 오답 포인트가 문장 끝.

## 3. 사회(법)
**머릿속 한 줄**: "요건이 곧 정답이다. 요건을 하나씩 건드려도 결론이 유지되는지, 누구 입장에서 쓴 문장인지를 본다."
- **법-기법1 "조건 + 결론" 선지** — 2.4점 일치도 "[상황]이라면 [효과]". 오답은 "~어야만"으로 필요조건화하거나 요건을 뺀다. **같은 한정어("~해야만")를 참 선지와 거짓 선지에 한 번씩.**
- **법-기법2 요건을 한 번에 하나씩 흔든다** — 요건표(요건/효과/예외), 오답 "[요건 X]가 없어도(~더라도) [효과]", 참 선지는 요건이 충족된 가정.
- **법-기법3 반대편 당사자의 입장** — 권리자/설정자/상대방/본인 양쪽 문장을 만들고 정답은 **의무 쪽 서술**.
- **법-기법4 숫자는 모두 참, 개념 선지가 거짓** — <보기> 날짜 표, 날짜 선지는 전부 정확히 계산 가능, 거짓 선지는 숫자 없는 개념(예: 지상권 범위 "토지 전부" → 설정자는 이용 불가). 정답 위치는 숫자 선지 사이. 앞참뒤거짓(14④)도 함께. **회차마다 반대 패턴(날짜 선지 하나가 틀림, 기산일)도 섞는다**(`05` 7).
- **법-기법5 자리 바꾼 참말** — 지문 속 제도 3~4개의 참인 문장을 표로 모은 뒤 다른 칸의 참말을 이 칸으로 옮긴 것이 오답. 이유 추론의 원 방식은 "참말 2 + 비튼 재료 2"(오답이 모두 지문에서 온 재료라 이의가 적다).
- **법-기법6 어휘·단답** — 법 한자어 문맥 풀이(독과점·전락·일탈·대등·행사), 정답은 방향이 다른 풀이("일탈"→"포기·철회"). 단답은 사례 속 구조를 용어로(출처를 본문/<보기>로 갈라 혼동 유도).
- **법-기법7 <보기> 문장마다 요건 하나** — 요건표에서 3~4개를 골라 <보기> 문장 하나에 하나씩, 법률 용어 대신 상황으로("과실"→"확인했더라면 알 수 있었다"). **정답 열쇠는 표의 작은 칸·수식어**(13번 "범위 토지 전부"). 쓰이지 않는 미끼 정보도 넣는다.
- **법-기법8 오답에 지문에 없는 법률어** — 철회·상속인·민사 소송 등을 오답 1~2개에만. 틀린 이유는 **지문 요건으로** 설명돼야 한다(용어가 없다는 것만이 근거면 이의).
- **체크리스트**: 주체가 지문과 맞는가 / 숫자 선지 모두 검산 / 오답당 바뀐 곳이 요건·주체·효과 중 한 곳 / 이유 추론 오답 재료가 지문의 다른 제도에서 왔는가 / <보기> 문장마다 요건 하나, 열쇠가 눈에 덜 띄는 칸 / 같은 한정어를 참·거짓에 한 번씩.
- 중간고사 사회는 전부 법 지문이었다. 경제·독점·공정거래·정치 지문에는 법 틀(요건 흔들기, 반대편 당사자)을 쓰지 않는다.

## 4. 과학·기술
**머릿속 한 줄**: "과정은 단계로, 변화는 방향으로, 제한은 숫자로 바꿔서 묻는다."
- **S1 한 낱말만 교체** — 지문 참인 문장을 복사하고 교체 대상을 네 종류(용어 쌍: 전기↔신경 신호·소리 높낮이↔크기·증발기↔응축기 / 속성 쌍 / 수량 / 위치·방향) 중 하나로. 참 선지는 인접한 두 문장을 합쳐 재진술.
- **S2 단계·수준 바꿔치기** — 경로표(단계/단위/입력/출력/특징), 오답 = 인접 단계의 기능을 이 단계로 옮김. 참 선지는 가정(질환으로 막힘, 흩어져 있어도)을 달아 같은 경로를 다른 상황에서.
- **S3 제한 조건을 숫자·단서로** — 지문의 "~까지만/~만" 문장을 <보기> 단서(수치)로, 정답은 한계를 **우회하는 두 번째 기제**.
- **S4 역설형 <보기>** — 모순처럼 보이는 상황 → 해소하는 근거 문장 두 개 → 오답은 가짜 기제 3(그럴듯한 부위·이름) + "한 지문 특성을 양쪽에 붙인 공통점" 1.
- **S5 비대칭 추론** — 순서가 있는 공간 + 곡선 모양(↑ 최대 ↓) → 두 입력이 겹칠 때 누가 누구에게 영향을 주는가. 오답: 비례 방향 반대, 한계 무시, 정보 종류 혼동.
- **S6 수치는 참, 마지막에 두 변수 동시 변경** — 관계식에 수치를 넣어 참 계산 선지를 먼저, 오답은 직관값(조건 문장에서 분자 변화가 보이지 않게: "흡수 열량을 유지한 채").
- **S7 what-if 인과 사슬** — 변수 하나 변경 → 에너지 분배 → 온도·시간 결과, **고리 한 곳만** 틀리고 결론은 그럴듯.
- **S8 이식 추론** — 같은 물리 사건(응축 = 열 방출)을 짝지어 정답, 오답은 한쪽에만 있는 특성을 "모두"로 넓힘.
- **S9 양보절이 붙은 참 선지** — 법은 요건 제거가 효과를 없애지만, 과학은 **원리가 유지됨**을 확인하는 용도.
- **S10 어휘 근접 뜻풀이** — 한자어 5개의 뜻풀이, 오답은 유의어의 뜻풀이. 사전 대조 필수.
- **S11 표는 지문 서술어의 수치화** — 지문 "상승/일정/감소"를 수치로 바꾸고 이름표(구간 이름)는 A·B·C로 가림, 계산 기준값은 단서 "(단, …)"로. 선지는 "[표의 현상]은, [지문 원리] 때문이다".
- **S12 지문 끝 부가 정보에 없는 인과** — 마지막 문단 한 문장을 참이면 <보기>에 적용, 거짓이면 "~하면 ~를 막을 수 있다"를 붙임.
- **체크리스트**: 오답이 한 낱말(용어·속성·수량·위치)만 다른가 / 수치 선지 모두 검산, 오답이 직관값 / 한계가 <보기>에서 수치·단서로 쓰였는가 / 가짜 기제 이름이 지문에 없는 부위·용어인가 / "모두" 선지가 한쪽 지문의 특성을 붙인 것인가.

## 5. 예술 (세 파트에 딱 맞지 않음)
- 선지 35~50자로 가장 짧다. 길이 단서가 없으니 "모두/달리"의 극성과 학자 짝 바꾸기로 변별. <보기>는 실존 외부 이론·실제 작품·ㄱ~ㄹ 진술.
- **A1 "A와 달리 B는"의 전제가 거짓** — 두 학자의 공통점을 "A와 달리 B는 [공통점]"으로 쓴다(27④).
- **A2 실존 외부 이론을 분류틀로** — 3분류 이론을 5~6문장 요약. 선지 3개는 지문 속 실제 사건, 2개는 "~했다면" 가정 장면(정답은 가정 장면일 때가 있음).
- **A3 진술 × 학자 조합** — ㄱ~ㄹ 진술에 "만·명확하게·가장" 같은 한정어. 소거로 풀리기 쉬우므로 **세트당 1개까지**, 정답의 양쪽 판단이 모두 지문 근거를 갖게 원 문항보다 엄격하게.
- **A4 앞절 참 + 뒷절 거짓, 인물 교체** (31②, 32⑤). 30번은 "누가 누구에게" 방향과 "~만·배제"로.
- 오답 넷 모두 극단어 하나로 틀리게 하지 않는다(극단어 오답은 하나까지).

## 6. 유사문제 한 문항 만드는 순서 (n제)
1. 파트를 고른다(철학·사상=인문, 제도·법=법, 과정·장치=과학, 예술이론=예술).
2. 급소표를 만든다: 인문 입장표(학자 × 인정 × 부정 × 사례) / 법 요건표(제도 × 요건 × 효과 × 예외) / 과학 경로표(단계 × 단위 × 변화 × 한계).
3. **정답 문장을 먼저** 쓴다(급소표 한 칸의 재진술, 또는 두 칸 합침).
4. 오답은 파트별 변조 규칙으로(인문: 방향·정도·시간 한정어·학자 귀속 / 법: 요건 제거·추가, 제도 맞바꿈, 자리 바꾼 참말 / 과학: 한 낱말·단계 이동·가짜 기제·직관 계산값).
5. <보기> 설계(인문 서사 + 지문 어휘, 법 날짜·사례, 과학 표·수치·단서). 지문에 없는 상황을 쓰되 정답 근거는 지문 문장.
6. 검증: 정답 근거 문장 번호가 지문에 있는가 / 오답마다 틀린 곳이 정확히 한 군데인가 / 숫자·날짜 계산 / 정답이 유일한가.
