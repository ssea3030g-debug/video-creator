# 04. 모의고사 체제와 선생님 힌트 (압축본)

> 원문: `docs/모의고사용-지침서.md`(6KB) + 출제분석 지침서 14장. 선생님 언급은 두 문서에 중복되어 여기서 한 번만 쓴다. v2 세트 표(지문 구성)는 제작 규칙이 아니라 v2 결과이므로 뺐다(원문에 있다). 선생님 힌트의 번호는 **올림포스 해설지의 분야별 번호**(예: "인문 9번")이며 중간고사 문항 번호와 다르다.

## 1. 전체 체제
- 9세트, 선택형 33 + 단답형 2 = 35문항, 100점(선택형 95 + 단답형 5).
- 지문 배열: 인문 → 사회 → 과학·기술 → 예술.
- 단답형은 시험지 맨 끝에 모으지 않고, 해당 지문의 선택형 바로 뒤에. 세트 지시문에 "[6~9, 단답형 1]"처럼 함께 적는다.
- 분량: 중간고사처럼 14쪽 안팎.
- 모의고사는 두 지문을 (가)(나)(다)로 엮고, n제는 지문당 4문항으로 분리한다.
- 지문은 **원문만** 쓴다(원본에 없는 지문을 새로 써서 (나)로 붙이지 않는다). 계산에 식이 필요하면 해당 문항 <보기> 안에 짧게(예: C = ε × A/d, 상호 정전 T = M × N × t₀).

## 2. <보기>와 배점
- <보기> 문항은 16개 안팎(중간고사 33문항 중 16개, 3.0점 이상 15문항 중 12개). 너무 많으면 안 된다. 한 지문에 몰리면 하나를 일반 추론·어휘로 바꾼다. 선생님이 언급한 <보기>는 남긴다.
- 배점 2.4~3.3으로 넓게. 3.0점 이상 15문항(그중 3.1~3.3점 11문항). 3.3점은 3지문 종합·계산형·농도/조건 실험형 같은 최고난도. 사전적 의미 문항은 3.2점.

## 3. 어휘 문항은 선생님이 직접 지은 선지로
중간고사 어휘는 사전 뜻풀이를 그대로 옮기지 않고 선지를 직접 지어 "아닌 듯 맞는 듯" 헷갈리게 냈다.
- 사전적 의미(중간 22번형, 발문 "가장 적절한 것"): 정답 하나만 사전 뜻풀이. 나머지는 한 단어만 바꿈(다시→처음으로, 가로→세로), 주체 뒤집기(속여 넘김→속아 넘어감), 비슷한 말의 뜻풀이(방치·확산), 소리가 같은 한자어(産出/算出).
- 문맥 풀이(중간 16번형): "문맥을 바탕으로 ⓐ~ⓔ를 이해한 것으로 적절하지 않은 것은?" 선지 "~라는 의미로 쓰였다". 틀린 선지는 비슷해 보이는 다른 뜻(억제→느리게 전달됨, 일탈→포기).
- 다의어(중간 29번형): 같은 단어의 다른 뜻 예문 4개를 직접. '눈앞에 보이다'처럼 가장 그럴듯한 다른 뜻을 매력적 오답으로.
- 구절 바꿔 쓰기(중간 32번형): 밑줄 구절을 가리키는 인물·개념으로 바꿔 쓰고 오답은 인물 교체(흄→플라톤).
- 단어 동의어 바꿔 쓰기(포획→사로잡기)는 쓰지 않는다. 뜻풀이는 표준국어대사전과 대조.

## 4. 기타
- 인터넷 검색으로 덧붙인 내용은 해설에 [검색].
- 정답 번호는 ①~⑤ 고르게.
- 결과물: `독서-고난도-모의고사-vN.pdf`(양식 `07`), 원문 md.

## 5. 선생님 힌트 (해당 지문을 쓸 때 반영)
**인문**
- 올림포스 인문 8번과 13번 지문이 예쁘게 이어진다 / 9번과 14번도(묶음·연계 구성에 활용). 9번 지문에서 주체 중심 철학 언급.
- 10번은 마지막 문단을 강조(마지막 문단을 비중 있게).
- 11번에서 표현주의는 "한마디부터 표현하려고 하였다"까지의 내용이 나온다고 말함.
- 7번은 **본문에 나오지 않은** 투영정전 방식의 단점을 유추하게 한다 → 본문에 없는 대상(방식)의 한계·단점을 지문 원리로 추론시키는 문항.
**과학·기술**
- 6강(눈): 백내장이 생겼을 때 초점 맞추기에 대해 질문 → 새 상황(백내장)에 지문 내용을 적용하는 <보기>·추론형.
- 7강(터치스크린): 휴대폰에 쓰이는 방식(상호 정전) 강조, 투영정전 방식은 구조 복잡·단가 높음(필기).
- 8강(생물과 독): 이독제독 언급. <보기>를 길게 하고 **해독제 3개**를 준 뒤 독과 해독제 작용으로 시험 내면 좋겠다 → 독과 해독제 세 가지 대응 관계를 <보기> 표·사례로.

## 6. 문항 아이디어 비축 (다음 회차에 쓸 것)
- **차선의 이론 — 사회무차별곡선의 '가중치'를 효용 공간 <보기>로** (2026-11-18)
  - 근거: 4문단 "우하향할수록 기울기가 완만 ← 높은 효용에 낮은 가중치, 낮은 효용에 높은 가중치(공평성 가치판단)". 지문 <그림>은 쌀·옷 축이라 가중치가 드러나지 않는다.
  - 틀: <보기>에 가로축 '갑의 효용', 세로축 '을의 효용'인 사회무차별곡선과 두 점(갑이 잘사는 점 P, 을이 잘사는 점 Q). 적용형 3.0점 안팎. 정답 방향: P에서 을의 효용 1을 줄이면 같은 사회후생 유지에 갑의 효용이 1보다 많이 늘어야 → 곡선이 완만.
  - 오답 기법: ①가중치 방향 뒤집기 ②P·Q 기울기 맞바꾸기 ③같은 곡선 위 점끼리를 '원점에서 멀수록 후생↑'로 비교 ④효용 공간 기울기를 생산가능곡선(효율성)과 혼동 ⑤쌀·옷 축에 가중치를 그대로 대응.
  - 주의: 효용 공간 그림은 지문 밖이므로 <보기>에서 축과 전제를 완결해서 제시. 숫자는 1단계 비교까지.
  - 단답 변형: "P에서 곡선이 완만한 것은 ( ㉠ ) 효용수준을 누리는 사람의 효용에 높은 가중치를 주기 때문" → 낮은.
