# 06. '최상' 메커니즘 (압축본)

> 원문: `docs/최상-메커니즘-학습.md`(5KB). 입력은 중간고사·v2·v3·v4 PDF 텍스트, 원문에는 중간고사·v2·v4 = 최상, v3 = 상으로 적혀 있다. **정정(2026-11-22): v2 등을 최상으로 본 판단은 Claude가 한 것이고 사용자가 확인한 등급이 아니다. 검증된 기준점은 중간고사뿐이며, v2·v3·v4 등급과 아래 M1~M8 중 v2·v4에서만 확인된 부분은 참고용이다.** **또한 사용자가 v4를 '자기 기준 중하'로 직접 판정했다(2026-11-22). 위 원문이 v4를 최상으로 본 것과 반대이므로, M1~M8의 '확인된 예' 중 v4 문항(v4 4·7·11·14·19·26·31 등)은 최상의 근거로 쓰지 않는다.** 원문의 원 분석(`docs/gemini-분석/`)은 flash-lite가 한 것이라 독자 판정이 사용자 판정과 어긋났다(해설의 자기 평가 문구 "L4"에 끌림). 그래서 **원문 문항으로 확인되는 것만** 남겼다.

## 1. '최상'을 만드는 메커니즘 M1~M8
| # | 메커니즘 | 핵심 | 확인된 예 |
|---|---|---|---|
| M1 | 다지문 종합 평가 | 3개 지문(학자)의 관점으로 하나의 가상 주장을 평가, 정답은 '일부 수용' | 중간 4, v2 4, v4 4 |
| M2 | (가)+(나) 메커니즘 결합 <보기> | 두 지문의 원리를 한 대상에서 동시에 통과해야 정오가 갈림 | 중간 20, v4 26 |
| M3 | 외부 이론 <보기>로 학자 재분류 | 지문 밖 이론 틀을 독해한 뒤 본문 학자를 다시 분류 | 중간 27·33, v4 11·31 |
| M4 | 서식·시계열 판정 | 등기부·타임라인 날짜로 효력·순위 판정. 날짜 선지가 참인 회차와 그 반대 회차를 섞음 | 중간 13·14, v2 11, v4 14·19 |

| M6 | 비대칭·방향성 추론 | 물리량의 방향·비대칭을 사례에 옮겨야 판정 | 중간 24 |
| M7 | 학자 귀속·개념 맞바꿈 + 참 선지 위장 | 오답은 귀속 교체, 참 선지는 이중 부정·양보절로 틀려 보이게 | 중간 2·28, v2 29, v4 7 |
| M8 | 어휘 핵심 자질 1개 변조 | 사전 뜻풀이의 방향·주체 한 자질만 교체(가로↔세로, 동음 한자어) | 중간 22, v4 5 |

## 2. v3가 '상'에 머문 이유 (같은 지문군 v2 대비)
1. 계산·조건 문항의 압박이 낮다(v2 12·21번에 비해 변수 연동이 적음, 2차 보완에서 일부 복원).
2. 한 문장 대조로 풀리는 선지가 남음(v3 1·18번 전개 방식, 31번 일부).
3. 오답 기법이 '앞절 참 + 뒷절 거짓'에 쏠림(약 45%). v2·v4는 이중 부정·직관값·조건 변조가 더 고르다.
4. 어휘 문항(5·25·30)이 지문 기전과 떨어진 독립 측정에 가깝다.
5. 외부 이론·융합 문항은 있으나 선지끼리의 얽힘이 v2 4번 수준에 못 미친다.

## 3. 다음 회차를 처음부터 '최상'으로: 체크리스트
1. M1 다지문 종합 평가 1문항 이상(인문).
2. M2 (가)+(나) 결합 <보기>: 복합 지문 세트마다 1문항.
3. M3 외부 이론 <보기> 2문항 이상.
4. M4 서식·시계열 문항: 법 세트에 1문항 이상. 날짜 선지만 참인 패턴 반복 금지.
5. M5 계산 + 조건 변경 2문항 이상, 오답에 직관값 1개 이상.
6. M6 비대칭·방향성 추론 1문항(과학).
7. 참 선지 위장(이중 부정·양보절) 3문항 이상.
8. **오답 기법 분포: 앞절 참 + 뒷절 거짓은 40% 이하.** 개념 맞바꿈·귀속 교체, 조건 변조, 인과 역전, 직관값을 고르게. (원본 중간고사는 30% 안팎, v3의 약점이 이 쏠림)
9. 한 문장 대조로 즉시 소거되는 선지는 문항당 1개 이하. 일치형(L1)은 회차당 3문항 이하('0개' 강제 아님).
10. 어휘 문항은 지문 기전과 연결되는 단어를 고르고 M8 방식으로 변조.
11. 전개 방식 문항은 '구조는 같고 장치가 다른' 짝을 정답으로(H5). "A와 달리 B는" 공식형만으로 소거되지 않게.
12. 단답형은 사례 추론형(지문 개념 + <보기> 인물), 음절 힌트 금지.
13. **분석·검증을 외부 모델에 맡길 때는 자기 평가 문구(L4 등)를 넣지 않는다.** 판정이 끌려간다. 문제지만 넘긴다.
