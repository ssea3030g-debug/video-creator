# 07. 시험지 편집 형식 (압축본)

> 원문: 출제분석 지침서 13장(HWP 설정값 포함, 약 6KB)과 `docs/중간고사-편집형식.md`(3KB)를 합쳤다. PDF는 `tools/make_exam_pdf.py`(reportlab + Chromium)로 만든다. 기준 양식: `docs/독서-고난도-모의고사-v2.pdf`.
> 한글 폰트: 컨테이너 기본에 없다. `apt-get update -q && apt-get install -y -q fonts-nanum fonts-noto-cjk`(확인: `fc-list :lang=ko | grep -i nanum`). 본문 NanumMyeongjo, 제목·번호 NanumGothic.

## 판형·글꼴 (원본 14쪽, 한글 HWP 2020 → PDF)
- A4 세로, 좌우 여백 약 11mm, **2단**(단 너비 약 89mm, 한 줄 약 28~30자, 가운데 세로선·2쪽부터 이중선).
- 본문(지문·발문·선지·안내·저작권)은 전부 굴림 9pt, 줄 간격 약 11.7pt(130%), 양쪽 정렬. 지문 각주 8pt, <보기> 안의 표·흐름도 7~7.6pt, 수식 10pt(아래 첨자 6.8pt). <보기> 제목의 꺾쇠 "< >"만 휴먼명조. 굵게는 발문과 ⓐ·㉠ 기호에만.
- 상단 제목(굵은 고딕 20pt) "20XX학년도 제 N학기 …과 문제지" + 굵은 가로줄, 오른쪽 쪽 번호 `n/N`(12pt, 둥근 테두리). 모든 쪽 같은 제목.
- 쪽 하단: 저작권 문구 두 줄 + 오른쪽 `☞다음 면에 계속`. 마지막 쪽은 마지막 문항 아래 오른쪽 정렬 `끝. 수고했습니다.` (연습용이면 "연습용" 문구).

## 1쪽 머리
1. 제목 줄 + 굵은 가로줄. 2. 정보표(실시일·출제자) + 오른쪽 결재란(교과주임·계·부장·교감·교장). 3. 응시 안내 상자(※ 반·번호·이름·과목코드 입력 / 선택형 33문항, 단답형 2문항 / 단답형 답은 OMR카드 **앞면**에 **검정색 볼펜**(굵게·밑줄)). 4. 세트 지시문. 2쪽부터는 제목 줄만.

## 세트·문항
- 세트 지시문 `[1~5] 다음 글을 읽고 물음에 답하시오.` / `[6~8, 단답형 1] …`. 지문은 **테두리 상자**, 문항은 상자 밖. (가)(나)(다)는 같은 상자에서 빈 줄 하나로 구분. 지문은 단·쪽을 넘어 이어진다. **각 지문은 새 쪽에서 시작**(공백이 남아도 됨).
- 발문 `번호. 발문 [배점점]`, 번호와 발문 전체 굵게, '않은'에만 밑줄. 배점 소수 한 자리.
- 선지 ①~⑤ 줄마다 하나, 둘째 줄부터 내어쓰기. 어휘 문항 선지는 짧게. 문항 사이 빈 줄, 단 하단에서 문항이 끊기지 않게 단 이동.
- <보기>: 테두리 상자, 위 테두리 가운데 `< 보 기 >`, 표는 7pt대, 단서는 `(단, …)`.
- 단답형: `[단답형 1] … 쓰시오. [2점, 각 1점]` + <보기> + 답란 `㉠: (          ), ㉡: (        )`. 해당 지문 선택형 바로 뒤.
- 밑줄 기호 ⓐ~ⓔ·㉠~㉢는 어구 바로 앞에, 굵게+밑줄. 원문자 ①~⑤, ⓐ~ⓔ, ㉠~㉤, ㉮~㉱ 출력 확인됨(Nanum).

## 사용
```bash
python3 -I tools/make_exam_pdf.py <문항.md> <지문.md> <출력.pdf> "독서 고난도 모의고사" "[1~4] 다음 글을 읽고 물음에 답하시오." [그림.png]
```
(도구: reportlab, pypdf, LibreOffice `soffice`, pandoc. 1~2쪽만 그림으로 확인.)
