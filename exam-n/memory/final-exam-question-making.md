# 국어(독서와 작문) 기말 범위 문제 제작 (2026-11-13 기준)

- 2026학년도 2학기 중간고사(2학년 독서와 작문) 시험지를 올려, 출제자의 사고 과정과 분야별(예술·사회·인문 등) 출제 방식을 철저히 분석한 지침서를 만들어 달라고 함 → `docs/` 의 출제 분석 지침서 / 파트별 출제자 사고방식
- 기말 범위 문제를 만들 계획이며, 그때 이 지침서를 참고하기로 함 (현재 범위 지문 PDF `docs/원본발췌_26선_통합본.pdf` 로 문제 제작 진행 중)
- 분석할 때 올림포스 해설지(`docs/EBS_2026_올림포스...txt`)를 이용하라고 함
- 독 지문(「생물과 독」) 선생님 힌트: '이독제독'을 언급했고, <보기>에 해독제 3가지를 주고 독과 연관시키는 <보기> 문제로 내면 예쁠 거라고 함
- 터치스크린 패널 지문 선생님 힌트: 수업에서 휴대폰에 쓰이는 방식(상호 정전 방식)을 강조했고, 지문에 없는 상호 정전 방식의 단점을 표면 정전 방식 내용으로 유추하게 한다고 함
- 제작 방식: 두 지문을 (가)(나)로 엮는 것은 모의고사용이라고 보고, 지금은 지문을 각각 분리해 한 지문당 4문항씩 만들기로 함
- 유사문제를 n제 형태로 다 만들어 모아 둘 계획이라, 정답 번호 비율·배점 합 같은 것은 필요 없다고 함
- 과학·기술, 사회, 인문 파트를 맡은 선생님이 다 다르므로, 파트별 출제자 사고방식을 따로 분석해서 그에 맞춰 유사문제를 만드는 것이 중요하다고 함 (이미 만든 문제를 다시 만들 필요는 없다고 함)
