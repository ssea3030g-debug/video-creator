# 보완 계획서 — S5·S6 보정 결과 반영 (문제 제작 개편 세션용)

근거: `exam-n/sets/calib/요약.md` (추정, 정답률 데이터 아님 · 모델 gemini-3.5-flash-lite라 검증 약함 · 브랜치 `ccr-5309b1b0-1a0ni9`).

## 1. 판단 요약
- S5(지문 없이 확신≥4 맞힘)는 '않은' 발문에서 기준점 92%·최상 76%가 걸려 **신호가 아니다**. 긍정 발문 기준선은 기준점 19%, 최상 38%.
- 파일럿 긍정 발문 3문항 중 2문항 적중(n이 작아 '기준보다 쉬움'을 단정할 수 없음). 가장 유력한 쉬움 후보는 **Q1(전개 방식)**. Q3은 v2 수준, Q2는 기준과 비슷, Q4는 S5로 판단 불가.
- v2(최상)는 긍정 발문 정답이 가장 긴 선지인 비율이 81%로 **길이 단서가 있다**. 파일럿에는 없다(0/4). 기준점도 전체 50%라 현재 S3 임계(40%)는 너무 낮다.
- S1 복사도 0.6 임계는 기준점·최상 모두 0건으로 의미 없음.

## 2. 해야 할 일 (우선순위)
1. **S5 규칙 수정**: 긍정 발문만 대상, 세트 단위(긍정 발문 적중 > 40%면 쉬움 후보)로 판정. `check_hard.py`/`blind_solve.py` 판정문과 `tools/README.md` 기준값 표를 이에 맞게 수정(제안만 README에 적어 둠, 코드 기본값은 아직 그대로).
2. **S3 규칙 수정**: 긍정 발문 정답 최장 비율 > 50%로, '않은' 발문은 분리 집계. ±35% 이탈 신호는 긍정 발문 순위 1위만 남기고 참고로 강등.
3. **S1 재정의**: 정답-오답 복사도 차이(≥0.15) 기준으로 바꾸거나 신호에서 내린다.
4. **파일럿 Q1 재작업 후보 검토**: 전개 방식 문항이 지문 없이 확신 4로 풀림. 선지 구조·표현 단서를 점검(지침서 기준 검수는 사용자 허락 후).
5. **정답키 직접 대조**: S6 불일치(모델 확신 5) 중간고사 22·30·33, v2 24·25. 모델이 lite라 오류일 가능성이 크지만 v2 24·25는 해설과 대조 필요. 중간고사 키는 추정이므로 수정하지 않고 표시만.
6. **재측정**: `gemini-3.5-flash` 쿨다운(약 9시간) 해제 후 같은 명령으로 재실행(`import_exam.py`로 변환 → `blind_solve.py --sleep 2` 직렬 → `check_hard.py` → `calib_report.py`). 병렬 실행 금지(429로 쿨다운 유발).
7. **표본 확대**: 파트·배점대별 기준선은 칸당 15문항 이상 쌓인 뒤 판단. 다른 기출·모의 자료 추가 변환 후보.
