# 눈+독 복합 5문항 검증 메모 (경량 모드)
- 점검: 스크립트(선지 길이, 정답 분포), 무료 모델 맹검 풀이 1회(gemini-3.5-flash-lite; 3.5-flash는 시간 초과로 실패).
- 정답 분포: ③ ② ⑤ ① ④ (각 1개).
- 선지 길이(정답−오답평균, 글자): 1번 +13 / 2번 +7 / 3번 +9 / 4번 +5 / 5번 +2.
- 맹검 결과: 5문항 모두 정답 일치, 확신도 높음, 복수 정답·정답 없음 지적 없음. → 정답은 하나로 방어되나 AI에게는 쉬운 편. 실제 학생 난이도는 별도.
- 약한 문항: 2번(일치, 단어 한 곳 교체), 5번(어휘, '계속' vs '필요할 때에만'). 3번(경로 두 단계 + 생성 지속)과 4번(이독제독 직관 함정)이 핵심 문항.
- 한계: 서브에이전트·재검증은 하지 않음(토큰 절약).
