# exam-n/tools

| 파일 | 용도 | 토큰 |
|---|---|---|
| `check_hard.py` | 난이도 신호 S1~S4 + 형식 수치 + L 태그 정직화 (지문 복사도, 극단어 오답, 정답 길이, 기법 중복, 5축 합) | 0 |
| `blind_solve.py` | 무료 모델 맹검 풀이: 지문 없이(S5, 소거로 풀리는지) / 지문 주고(S6, 오류·모호 탐지) | 무료 모델 |
| `check_set.py` | 구형 점검(선지 길이·정답 분포·배점 합). `check_hard.py`가 대체하지만 남겨 둠 | 0 |
| `make_exam_pdf.py`, `make_exam_multi.py` | md → 시험지 PDF | 0 |
| `examlib.py` | 위 스크립트의 문항 md 파서 | — |
| `import_exam.py` | 2단 시험지 PDF(`pdf`)·모의고사 md(`md`) → examlib 형식 변환. 결과는 /tmp에만 둘 것(학교 저작물) | 0 |
| `calib_report.py` | 맹검·check_hard 결과 JSON → 자료별 비교표·문항별 JSON(`sets/calib/`) | 0 |

모두 표준 라이브러리만 쓴다. 실행은 `python3 -I`.

## 문항 md 형식
```
## SET 1 | [1~4] | s1.md           ← 세트 머리글(지문 파일명은 세 번째 칸)
**1. 윗글의 … 것은? [2.7점]**     ← 문항 머리글(한 줄, 굵게). '않은'은 <u>않은</u> 가능
> <보기> 본문                      ← <보기>는 > 인용
① … ⑤ …                           ← 선지 한 줄에 하나
```
정답표: `**N. ②** [근거: …]` 줄과 해설 끝줄 `난이도: L3 (A2 B1 C1 D1 E0, 합5)`(감점이 있으면 `, 감점 1단계` 추가)가 있는 md(또는 `--key 24135…`).
설계 카드(선택): `Q7 | 인문 | … | 근거: 2문단 + 4문단 | 오답 기법: ①맞바꿈 ②방향 ④한정어 ⑤다른 학자 참말 | …` 한 줄씩.

## 사용
```bash
cd exam-n/tools
python3 -I check_hard.py ../sets/pilot/s1.md --passage /tmp/s1.md --answers ../sets/pilot/s1.md --part 인문 --cards ../sets/pilot/cards.md
python3 -I blind_solve.py ../sets/pilot/s1.md --passage /tmp/s1.md --answers ../sets/pilot/s1.md --out /tmp/blind.json
python3 -I blind_solve.py … --dry-run     # 보낼 프롬프트만 확인(네트워크 없음)
python3 -I blind_solve.py … --sleep 2     # 호출 간격(429 방지). 한 호출이 실패해도 전체는 계속, 결과에 '실패/없음'으로 남음
# 429가 오래 가면(쿨다운) --model gemini-3.5-flash-lite 로 바꾸고 '검증 약함'으로 표시. 병렬로 여러 개 돌리지 말 것
```
- `blind_solve.py`는 FreeLLMAPI(`FREELLM_BASE`, 기본 `http://localhost:3001/v1`; 키는 `FREELLM_KEY` 또는 `~/.freellmapi-session/unified-key`)를 쓴다. 없으면 "미실시"로 보고하고 넘어간다.
- 정답표·해설·배점·난이도 태그는 모델에 보내지 않는다. lite 모델이 풀면 "검증 약함".

## 신호 기준값 (2026-11-22 반영, 기준점 = 중간고사)
> 근거: `sets/calib/요약.md`. lite 모델 1회 풀이·표본 작음 → **추정이며 정답률 데이터가 아니다.** 기준점은 중간고사뿐(v2는 Claude의 미검증 판단, v4는 사용자 판정 중하 — v4 결과는 보정 세션이 추가 측정 중). flash 모델·v4로 재측정하면 값이 바뀔 수 있다.
| 신호 | 현재 코드 기준 | 비고 |
|---|---|---|
| S1 지문 복사도 | 정답 선지 3-gram이 지문 한 문장에 ≥ 60% (--thr) | 기준점 0건 → 노골적 복사만 잡는 안전망. '쉬움' 판별용으로는 둔감 |
| S2 극단어 | 강한 극단어 오답 ≥ 2개 / 부정형에서 정답 선지에만 | 기준점 2건(희소) |
| S3 길이 | **회차에서 '긍정 발문' 정답 최장 비율 > 50%**만 신호. 문항별 1위·±35%·파트 길이대는 '참고'로만 출력 | 기준점: 긍정 38%, 전체 50%, ±35% 이탈 14건 → 문항별 신호는 변별력 없음 |
| S4 기법 | 한 문항 안 같은 기법 2회 이상, 회차 앞참뒤거짓 > 40%, 근거 한 곳뿐 | `--cards` 필요 |
| L | 해설 L 태그·합 표기가 5축 합과 어긋남, L3+ < 55% | v6에서 11건 어긋남 |
| S5 | **긍정 발문**에서 지문 없이 확신 ≥ 4 + 정답 → 후보. '않은' 발문은 신호 아님. **세트 단위** 긍정 발문 적중 비율 출력, 임시 경계 40% | 기준점 긍정 19%(3/16), '않은' 92%(12/13). 40%는 v2(미검증) 값이라 임시 |
| S6 | 지문 주고 정답과 다름 / 정답없음·둘이상 / 확신 ≤ 2 → 직접 대조 | 불일치는 lite 오판일 수 있음(기준점 키도 추정) |
| (도입 안 함) | 선지 중심값 지표, 확신 5만 보기, 파트·배점대별 S5 기준선 | 적중 우연 수준 / 구분력 없음 / 칸당 표본 ≤ 12 |
