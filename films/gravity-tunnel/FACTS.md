# FACTS — 42분 터널

화면의 모든 숫자는 아래 식과 상수로 계산했다. 같은 값을 `index.html`의 `R`, `G`가 매 프레임 계산에 쓴다.

| 주장 | 값 | 근거 |
|---|---|---|
| 지구 평균 반지름 | R = 6371 km | IUGG 평균 반지름 |
| 표면 중력가속도 | g = 9.81 m/s² | 표준 중력 9.80665 m/s²를 반올림 |
| 밀도가 균일한 지구 안에서 중력은 중심 거리에 비례한다 | a = −(g/R)·r | 껍질 정리(뉴턴). 반지름 r 안쪽의 질량만 당기고, 그 질량은 r³에 비례한다 |
| 직선 터널 위의 운동은 단진동이고, 각진동수는 터널의 위치·길이와 무관하다 | ω = √(g/R) | 터널 방향 성분 a∥ = −(g/R)·s (s는 터널 중점에서 잰 거리) |
| 반대편까지 걸리는 시간 | π√(R/g) = 2531.7 s = **42.2분 (42분 12초)** | 계산값(2531.7초를 반올림) |
| 중심을 지나는 순간의 속도 | √(gR) = 7906 m/s ≈ **7.9 km/s** | 계산값. 지표면 바로 위를 도는 원궤도 속도와 같다 |
| 실제 지구(밀도 불균일)를 중심으로 관통할 때 | 약 **38분** | A. R. Klotz, "The gravity tunnel in a non-uniform Earth", *American Journal of Physics* 83, 231 (2015). PREM 밀도 모형으로 계산 |

가정: 마찰과 공기저항이 없고, 지구 자전과 밀도 차이를 무시한다. 영상 끝의 작은 글씨에 이 가정과 "실제 지구 중심 관통은 약 38분"을 함께 적었다.

참고: Wikipedia 'Gravity train' 문서(접속 차단으로 원문 인용은 하지 못함). 위 수치는 직접 계산해 검증했다.
